# 規格・出力

[English (canonical)](04-standards-output.md)

図面は日本の産業慣習(JIS)に準拠し、画面と印刷品質ベクタ出力で同一に描画される。

## 利用できる機能

- **JIS図枠**: 用紙A4〜A0・縦横、ゾーン番号付き枠(横=数字、縦=英字)、表題欄(図番・品名・尺度・日付・設計/製図/検図/承認・社名・改訂記号)
- **図枠エディタ**: 図枠テンプレートダイアログの「編集…」/「新規 (コピーから)」で、テンプレートJSONを画面で編集するエディタが開く(形式は変えない)。ツールは選択・線と矩形(表題欄の罫線)・文字(固定文字)・プレースホルダ(`{project.name}`のようなバインド。出力時に実際の値へ置き換わる)・表題欄セル(大きさ付きのセルと外周の罫線)・ロゴ枠・ゾーン。プレースホルダは検索付きの一覧(プロジェクト/シート/改訂・表題欄)から選び、作図領域では隠す・現在のプロジェクトの実際の値で見せるを切り替えられる。1mmグリッドに吸い付き(Altで解除)、Shiftで線を水平/垂直に拘束する。右のパネルは選んだ要素を、何も選んでいなければ図枠全体(名前・用紙・マージン・ゾーンの分割数と目盛文字・表題欄の基準隅/大きさ/行高・改訂欄の行数と列幅)を編集する。エディタ内の`⌘Z`/`⇧⌘Z`はエディタ自身のundoで、図面の履歴には積まない。保存前チェックは未知のプレースホルダと枠外の要素を数え(どちらも保存はできる)、コアが拒む誤り(固定文字とバインドを両方持つ/どちらも無いセル・文字高0・改訂欄の列幅の合計が表題欄の幅と違う)があれば保存させない。保存先は`~/MadakeCAD/templates/frames/{id}.json`。同梱の図枠は上書きできないので、同梱から開いたものとコピーは新しいidで保存する(「別名で保存…」)。保存した図枠を使う全シートは、次の描画からキャンバス・SVG・PDFとも新しい図枠になる
- **図枠テンプレート(プロットフレーム)**: 枠・表題欄・改訂欄はコードではなく**データ**。JSONのテンプレートが余白・ゾーン文字の種類・表題欄のセル(罫線と、固定文字か**バインド**のどちらかを持つセル)・改訂欄を記述する。バインドは描画時に解決され、`{project.name}` `{project.no}` `{sheet.no}` `{sheet.total}` `{sheet.name}` `{rev.latest}` `{title_block.*}` と別名の`{date}` `{scale}` `{designer}` `{approver}`が使える。知らないバインドは図面を壊さず空文字になる。`{project.name}`・`{project.no}`は`Project.name`/`Project.no`が供給元で、「プロジェクト情報」ダイアログ(「回路図」タブ→「編集」グループ)または`set_project_meta`コマンドが設定する。同じコマンドは表題欄の欄(`{title_block.company}`・`{title_block.drawing_no}`・`{title_block.title}`)も全シートへ一括で書き込む(G16)。プロジェクト番号は3状態で、欄を送らなければそのまま・`null`を送る(ダイアログで空にする)と**未設定**へ戻る(空文字の番号は残らない)。undoはどちらの状態だったかまで正確に戻す。同梱は`jis-a3`(それまでのハードコード出力と1バイトも違わない)と`jis-a4-portrait`の2種で、自作は`~/MadakeCAD/templates/frames/`へ置く。選択ダイアログ(「管理」タブ→「テンプレート」グループ→「図枠テンプレート」。「プロジェクト」タブにも同じ導線)は表示中のシートでライブプレビューし、**値が空になる欄にだけ**`{バインド}`を青で重ねて見せる。「このプロジェクト」は**コマンド1回**で全シートの図枠を差し替え(キャンバス・SVG・PDFが同時に追従し、`⌘Z`一発で戻る)、「グローバル既定」は図面を変えず新規プロジェクトの初期値だけを決める。**用紙はテンプレートで変わらない**し、ゾーンの分割数もシートが正のまま(図枠を替えてもクロスリファレンスの指すゾーン住所が動かないようにするため)。シート自身の用紙サイズ・向きを作成後に変えるには「用紙サイズ」ダイアログ(「回路図」タブ→「編集」グループ)または`set_sheet_paper`コマンド(G15)を使う — 既存のエンティティ座標は描いたときのまま保たれ、ゾーンの分割数もシートが正のまま(用紙を変えても書き換えない)、新しい用紙の外に出たものは動かしたり消したりせずERC警告(`erc.outside_paper`)として報告される
- **改訂欄**: 表題欄の直上にISO 7200様式の表(列=記号/日付/内容/承認)。古い行が下、図枠には最大6行(それ以前の履歴もファイルには残る)。表題欄の改訂記号は常に最新行に連動。編集は改訂欄ダイアログ(「回路図」タブ→「回路図を編集」グループ→「改訂欄」)で、保存はコマンド1回=undo1回
- **シートとゾーン**: シートごとのゾーン分割設定。ゾーンアドレスがクロスリファレンスの参照先になる
- **シート間クロスリファレンス**: 同名のネットラベルはプロジェクト全体で1つのネット。各ラベルの脇に他シートの相手先アドレス(`/2.B3`。複数あれば並べて表示)を画面・SVG・PDFの全てで描画する。ラベルを選ぶとプロパティパネルに相手先が並び、クリックでそのシートへ切り替えて該当ラベルへズームする。跨ぎネットは帳票・ERCでも1ネットとして扱う。同じ住所表記は**デバイス単位**にも及ぶ: 2枚以上のシートに描かれた参照記号は、どのインスタンスの脇にも他シートの住所が同じ形式で出る(EPLANのクロスリファレンス種別でいうコイル/接点参照・デバイス参照に相当するものを、任意のシンボルへ一般化したもの)。リレーのコイル・接点は専用のコイル⇔接点クロスリファレンス([回路図エディタ](03-schematic-editor.ja.md)参照)を持つので、そちらが既に描いているぶんはここでは二重に描かない
- **SVG出力**: mm 1:1の印刷品質ベクタ。SVGレンダラが印刷見た目の唯一の正
- **PDF出力**: SVGのベクタ変換+フォント埋め込み(日本語対応)。1シート=1ページ
- **帳票9種**: From-Toワイヤリスト・端子台チャート・端子接続図・部品表(BOM)・ケーブル一覧・クロスリファレンス表・PLC I/Oレポート・盤内部品配置表・盤内配線図。端子台チャートとワイヤリストの列構成は[電線管理](05-wire-management.ja.md)を参照
- **盤内部品配置表**: 盤レイアウトシートのフットプリント1つ=1行で、アイテム番号/参照記号/型番/X/Y/レールの6列。X/Yは描かれる外形の左上角(モデルが持つ座標そのもの)で、レール番号は盤の上から順。アイテム番号はバルーンの番号であり、BOMの先頭列でもあるので、配置表とBOMは必ず一致する。リボン「パネル」タブ→「レポート」グループ→「配置表」。なお**アイテム番号列が増えたぶんBOMのCSVは旧4列版と非互換**になった
- **BOMのカタログ列**: 部品表の各行は型番を部品DBで引き当て、数量の後ろにメーカ/品名/単価/通貨/金額/購入先の6列を足す(全11列。**旧5列版のCSVとは非互換**)。部品行・電線集約行・付属品行のすべてを「型番/値」欄の文字列で引き、電線の「(未割当)」行と空の型番は引かない。部品DBに無い型番は行を残したまま6列を空欄にする。金額=数量×単価で、電線集約行の数量はmなので電線の単価は**1mあたり**として扱う(部品DBの登録もそれに合わせる)。単価・金額は小数第2位まで、末尾の0は書かない。単価が1つでも引けたときだけ、末尾に通貨ごとの「合計」行が付き、品名欄に単価が無くて合計から除いた行の数(`単価未登録 N 行を除く`)が入る。引き当ては帳票を書き出す入口(アプリ・MCP・Link API/`madake export`)で行い、部品DBを開けないときは6列が空欄になるだけ
- **盤内配線図**: 盤レイアウトシートのフットプリントごとに、回路図でそのピンに繋がる電線1本=1行で、盤/機器/型番/端子/線番/行き先/線色/線径sqの8列(CSVまたは図枠付きページ。CLIは`madake export panel-wiring`)。行き先は相手の`参照記号:ピン`かネットラベル。銘板の型番は部品表に型番ごとの数量行として載る
- **ケーブル一覧**: 多芯ケーブル1本=1行で、ケーブル/型番/芯数/線径sq/長さm/From機器/To機器/使用芯/予備芯/シールド/シートの11列(CSVまたは図枠付きシート。CLIは`madake export cable-list`)。両端の機器は芯線を割り当てた配線から読み、配線が消えた芯は予備芯として数える。部品表では付属品行の後ろに型番ごとの行が付き、その型番の全ケーブルに長さがあれば合計の長さ(`15.50 m`)、1本でも無ければ本数。型番の無いケーブルは載せない
- **BOMの端子台付属品**: 電線集約行の後ろに、付属品の型番ごとに1行(端子台エディタで端子台に付けたエンドブラケット・仕切り板・エンドプレート)。数量欄に使用個数、参照記号欄に使っている端子台が入る。型番の無い付属品と端子台チェックが読めない項は行を作らない。部品DBに無い型番も書いたとおりに載る(エディタが警告する)。制限: 付属品の幅は盤レイアウトのレール占有率・間隔チェックに**数えない**
- **BOMの電線集約**: 部品行の後ろに、プロジェクト全体で電線品番ごとの集約行が1行ずつ付く。数量欄にはその品番の総使用長(m単位・小数第2位まで、例`12.50 m`)が入り、品番が引けない配線([配線管理](05-wire-management.ja.md)参照)は勝手に品番を作ったり黙って落としたりせず「(未割当)」の1行にまとめる。配線の無いプロジェクトには集約行が付かないので、部品だけのBOMはそのまま。集約は行を足すだけで、列は増やさない。電線の行は部品行の個数と違い数量を**単位付き**(`3.75 m`)で書くので、長さを個数と取り違えない。品番を引けない配線に使用長が1本も無いときは`(未割当) 0.00 m`の行を出さない
- **PLC I/Oレポート**: 割り付けた1点=1行で、モジュール・アドレス・信号名・接続先・線番・コメントの6列。アドレス・信号名・コメントは[I/O割付表](03-schematic-editor.ja.md)から、接続先・線番は出力のたびに図面から読み直す。読む範囲は**そのモジュールが描かれている全シート**(生成すると元のシートとラダーページの両方に置かれるため)。リボン「レポート」タブ→「PLC I/O」グループ→「PLC I/Oレポート」、CLIは `madake export plc-io <path>`
- **帳票の図面シート化**: 全ての帳票をCSVでも**図枠付きA4横ページ**でも出力できる。回路図と同じJIS図枠・表題欄で、列見出しはページごとに繰り返し、長いセルは省略記号で切り、行が多ければ自動でページ分割する。端子接続図はグラフィカルな図面のため図面シート形式のみ
- **PDF一括出力(図面一式)**: 表紙(プロジェクト名・シート一覧・最新改訂)→ 回路図の全シート → 選択した帳票 を1つのPDFに綴じる。リボン「レポート」タブ→「出力」グループ→「PDF一括出力」、CLIは `madake export pdf-book <path> [--reports wire-list,terminal-chart,terminal-diagram,bom,xref,panel-placement] [--no-cover]`
- **帳票1種の書き出し**: `madake export bom|wire-list|terminal-chart|terminal-diagram|xref-table|plc-io|panel-placement|cable-list|panel-wiring <path> [--format csv|pdf] [--terminal <参照記号>]`(形式は省略時に出力先の拡張子から判定)

## 計画中

- **ロゴ画像**: テンプレートに枠(矩形)は置けるが、画像そのものの描画は未対応
- IEC / ISO対応: IEC 60617記号様式・IEC 81346構造指定子・ISO 7200表題欄・ISO 5457図枠(長期)
