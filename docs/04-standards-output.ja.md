# 規格・出力

[English (canonical)](04-standards-output.md)

図面は日本の産業慣習(JIS)に準拠し、画面と印刷品質ベクタ出力で同一に描画される。

## 利用できる機能

- **JIS図枠**: 用紙A4〜A0・縦横、ゾーン番号付き枠(横=数字、縦=英字)、表題欄(図番・品名・尺度・日付・設計/製図/検図/承認・社名・改訂記号)
- **シートとゾーン**: シートごとのゾーン分割設定。ゾーンアドレスは将来のクロスリファレンスの基盤
- **SVG出力**: mm 1:1の印刷品質ベクタ。SVGレンダラが印刷見た目の唯一の正
- **PDF出力**: SVGのベクタ変換+フォント埋め込み(日本語対応)。1シート=1ページ
- **部品表(CSV)**: 参照記号+型番の集計
- **電線リスト(CSV)**: 電線品番・線色・sq・長さ

## 計画中

- **改訂欄**: 図枠上の改訂履歴表の描画と編集UI(データモデルは実装済み)(M2)
- **シート間クロスリファレンス**: ネットラベル脇の相手先シート/ゾーン表示、プロジェクト全体のネット連続性(M2)
- **端子台チャート**: 端子台ごとの結線表(帳票+図面シート生成)(M4)
- **帳票群の拡充**: From-Toワイヤリスト・ケーブル一覧・クロスリファレンス表・部品DB連動BOM。帳票の図面シート化とPDF一括出力(M4)
- **図枠・表題欄テンプレートのカスタマイズ**(組織ごとの様式に対応)(M4)
- IEC系のシンボル・図枠様式(長期)
