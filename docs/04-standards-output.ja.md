# 規格・出力

[English (canonical)](04-standards-output.md)

図面は日本の産業慣習(JIS)に準拠し、画面と印刷品質ベクタ出力で同一に描画される。

## 利用できる機能

- **JIS図枠**: 用紙A4〜A0・縦横、ゾーン番号付き枠(横=数字、縦=英字)、表題欄(図番・品名・尺度・日付・設計/製図/検図/承認・社名・改訂記号)
- **改訂欄**: 表題欄の直上にISO 7200様式の表(列=記号/日付/内容/承認)。古い行が下、図枠には最大6行(それ以前の履歴もファイルには残る)。表題欄の改訂記号は常に最新行に連動。編集は改訂欄ダイアログ(「回路図」タブ→「回路図を編集」グループ→「改訂欄」)で、保存はコマンド1回=undo1回
- **シートとゾーン**: シートごとのゾーン分割設定。ゾーンアドレスがクロスリファレンスの参照先になる
- **シート間クロスリファレンス**: 同名のネットラベルはプロジェクト全体で1つのネット。各ラベルの脇に他シートの相手先アドレス(`/2.B3`。複数あれば並べて表示)を画面・SVG・PDFの全てで描画する。ラベルを選ぶとプロパティパネルに相手先が並び、クリックでそのシートへ切り替えて該当ラベルへズームする。跨ぎネットは帳票・ERCでも1ネットとして扱う
- **SVG出力**: mm 1:1の印刷品質ベクタ。SVGレンダラが印刷見た目の唯一の正
- **PDF出力**: SVGのベクタ変換+フォント埋め込み(日本語対応)。1シート=1ページ
- **帳票5種**: From-Toワイヤリスト・端子台チャート・端子接続図・部品表(BOM)・クロスリファレンス表。端子台チャートとワイヤリストの列構成は[電線管理](05-wire-management.ja.md)を参照
- **帳票の図面シート化**: 全ての帳票をCSVでも**図枠付きA4横ページ**でも出力できる。回路図と同じJIS図枠・表題欄で、列見出しはページごとに繰り返し、長いセルは省略記号で切り、行が多ければ自動でページ分割する。端子接続図はグラフィカルな図面のため図面シート形式のみ
- **PDF一括出力(図面一式)**: 表紙(プロジェクト名・シート一覧・最新改訂)→ 回路図の全シート → 選択した帳票 を1つのPDFに綴じる。リボン「レポート」タブ→「出力」グループ→「PDF一括出力」、CLIは `madake export pdf-book <path> [--reports wire-list,terminal-chart,terminal-diagram,bom,xref] [--no-cover]`
- **帳票1種の書き出し**: `madake export bom|wire-list|terminal-chart|terminal-diagram|xref-table <path> [--format csv|pdf] [--terminal <参照記号>]`(形式は省略時に出力先の拡張子から判定)

## 計画中

- **ケーブル一覧**: 多芯ケーブルがエンティティ化された後(M4)
- **部品DB連動BOM**: メーカ・価格・購入先の列を引き当てて追加(M4)
- **図枠・表題欄テンプレートのカスタマイズ**(組織ごとの様式に対応)(M4)
- IEC / ISO対応: IEC 60617記号様式・IEC 81346構造指定子・ISO 7200表題欄・ISO 5457図枠(長期)
