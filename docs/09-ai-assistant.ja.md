# AIアシスタント

[English (canonical)](09-ai-assistant.md)

MadakeCADはアーキテクチャからAI-first: アシスタントは人間と全く同じCommand APIで図面を編集するため、AIの編集はすべてundo可能・リアルタイム描画・監査可能。

## 利用できる機能

- **アプリ内チャット**: 左ドックパネル+キャンバス上の浮きカード。ストリーミング応答。会話履歴はプロジェクトと一緒に保存
- **プロバイダ6経路**: Claude Code CLI / Anthropic API / GitHub Copilot CLI / OpenAI互換API / Ollama(ローカル) / Google Gemini から選ぶ(下の[プロバイダ](#プロバイダ)参照)。どれを選んでも同じプロセス内MCPサーバーから同じツールを受け取るため、編集はCommandエンジン・undo履歴・リアルタイム描画を通り、チャットの見え方も変わらない
- **ツールの透明性**: 各ツール実行を会話内チップで表示(✓ place_symbol …)、「適用済み rev N」を記録
- **安全なターン巻き戻し**: 各ターンには安定したターンID、各履歴エントリには編集origin(user / agent / mcp)が付く。「このターンを元に戻す」は**エージェントの編集だけ**を逆適用するため、ターン中・ターン後の手編集は残る。手編集で逆適用できなくなった場合(対象が消えている等)は、途中まで戻さずターンをそのままにして衝突を報告する。巻き戻し自体も通常の履歴エントリなので、undoで取り消せる。**並列会話での粒度**: 編集の由来は「エージェントか否か」までしか分からない(MCPの入口が会話を名乗らない)ため、別の会話のターンと編集が混ざった区間を戻すと**両方のターンがまとめて戻る**。巻き込まれたターンも巻き戻し済みとして扱い、「適用済み」表示のまま空振りする「元に戻す」を残さない
- **検証ループ**: 図面を編集したらエージェントは必ず`run_verification`を実行し、エラーが残れば直して再検証する(最大3回)。最終応答には必ず「検証: エラー0・警告1」の形で件数を書く。3回で消えないエラーは、いじり続けずに残っている指摘と原因を説明する
- **規格知識**: 編集可能なMarkdownノート(`resources/knowledge/standards.md`)を毎ターン注入 — JIS C 0617記号の使い分け、参照記号の接頭辞、線色/sqの慣習と許容電流、線番・ハーネスの決まり、グリッドとレイアウト、標準の作図手順、各診断コードの読み方。「図面の自動読み取り」がOFFでも規格知識は必ず載る。**設定 > エージェント > 詳細設定 > 知識ファイル**で自社のMarkdownを後ろに追記でき、後勝ちで上書きできる
- **出典付きのドキュメント回答**: `docs/`の目次をエージェントへ渡し、操作方法・規格・対応状況の質問には**推測せずファイルを読んでから**答え、出典を書くよう指示している(例: `出典: 05-wire-management.ja.md`)。未対応の機能はロードマップで「M4で対応予定」と答える(創作しない)
- **設計レビューと検証計画**: 「レビューして」で`run_verification`の決定的な指摘と、人が見ないと分からない5観点(参照記号の体系・線色/sqの慣習・ラベル命名・レイアウト・図枠情報)を1つの指摘一覧(重要度順)にまとめる。修正は提案までで、承認後に実行する。「動作確認手順を作って」には操作→期待結果の手順表で答える
- **部品選定**: `search_parts`を根拠に比較表(最大10件。定格・価格・購入先と「現行品との差分」列)と代替提案を返す。配置済み部品の置換は提案までで、実行は承認後
- **開始テンプレート**: 同梱3種(24V制御基本・モータ起動回路・非常停止回路)は**履歴1エントリ**として適用されるため、undo一発でまるごと戻る。リボン「プロジェクト」タブ・部品挿入グループ・エージェントの`list_templates`/`apply_template`から使え、`~/MadakeCAD/templates/*.json`で自作テンプレートも追加できる
- **整えポップアップ**: チャット入力欄の杖ボタンで「自動で整える」を開く — **配置整理 / 配線整理 / ラベル整頓**。モードを押すと普通のターンが1回送られ、そのプロンプトが「`get_tidy_metrics`で測る(配線の交差数・ラベルの重なり・シンボルの重なり・グリッド外の点)→ 直す → もう一度測る」を指示する。**改善が止まったら、または3回**で終え、最後にビフォー/アフターの数値を報告する。1回の整え=1ターンなので、**undo一発でまるごと戻せる**。選択があればその要素だけが対象(「これ以外は動かさない」)、選択が無ければシート全体。ポップアップを使わず言葉で頼んでも同じループを回す(規格知識にルールが入っている)。整えでは接続を変えない・部品を足したり消したりしない・文字を書き換えない
- **並列会話**: 複数の会話を同時に走らせられる。1つ目が答えている途中でも、別の会話へ切り替えれば送信できる(同じ会話の中は従来どおり1ターンずつで、送信ガードは**開いている会話**にだけ効く)。会話には開始順に4色のパレットから色が割り当てられ、キャンバスの**編集オーバーレイ**、会話一覧の行ドット・スピナー、タブ行の「N会話実行中」バッジで同じ色を使う
- **編集オーバーレイ**: エージェントの編集領域をキャンバス上でパルス表示(会話ごとの色)。AIがどこを触っているか常に見える
- **図面コンテキスト**: ターン開始時に現在シートの要約(シート・ネット・検証サマリ=エラー/警告/情報の件数と重要度順の先頭数件)をエージェントへ供給
- **キャンセルの安全性**: エージェントイベントにターンseqを付け、キャンセル済みターンの遅延イベントは破棄する(次の会話へ紛れ込まない)

2つ以上の会話が同時に走っている間は、ツール呼び出しではなく図面patch由来のハイライトだけ既定色で描く(patchはどの会話の編集かを持たないため)。

## プロバイダ

**設定 > エージェント > プロバイダ**で6経路から選ぶ。必要なのは**どれか1つ**で、Claude Code CLIは既定というだけで必須ではない。

| 経路 | 認証方式 | 必要なもの | 確認済みの範囲 |
|---|---|---|---|
| **Claude Code CLI**(既定) | CLI自身のサインイン(Claude Pro/MaxのOAuth)。MadakeCADは資格情報を持たない | サインイン済みの`claude`(実行ファイルのパスは任意で指定可) | ✅ 作図の通し確認済み |
| **Anthropic API** | APIキー → OSキーチェーン(`anthropic_api_key`) | Anthropic Consoleのキー、モデル(既定`claude-sonnet-5`) | 🔶 UI・401の表示・キー未設定の案内まで。**実キーでの通しはユーザー確認事項** |
| **GitHub Copilot CLI** | CLI自身のGitHubサインイン。**MadakeCADはトークンを保存しない** | `copilot`(`npm i -g @github/copilot`)を`copilot`→`/login`でサインイン(または`GITHUB_TOKEN`/`GH_TOKEN`/`COPILOT_GITHUB_TOKEN`)。パス欄・モデル欄(既定`auto`)は任意 | 🔶 起動フラグ・MCP設定の形・未認証の検知まで。**`/login`と通し1ターンはユーザー確認事項** |
| **OpenAI互換API**(OpenAI / xAI / OpenRouter 等) | APIキー → OSキーチェーン(`openai_compat_api_key`) | 接続先URL(既定`https://api.openai.com/v1`)**と**モデル名(接続先ごとに名前が違うので既定値は置かない) | 🔶 モックでのツール往復。同じ実装がOllamaで実証済み |
| **Ollama(ローカル)** | 不要(ローカルURLならAuthorizationヘッダごと省く) | 起動中のOllama。**「Ollama (ローカル)」プリセット**ボタンが`http://localhost:11434/v1`を入れる。`ollama show`のCapabilitiesに`tools`があるモデルを選ぶこと | ✅ 実機で作図の通し確認済み |
| **Google Gemini** | APIキー → OSキーチェーン(`gemini_api_key`) | Google AI Studioのキー、モデル(既定`gemini-2.5-flash`) | 🔶 実エンドポイントが無効キーを弾くところまで。**実キーでの通しはユーザー確認事項** |

Ollamaは独立したバックエンドではなく、**OpenAI互換経路のローカルプリセット**。

**経路ごとに隠しきれない差**: どの経路も同じツールループ(1ターンあたり最大16往復)をMadakeCAD自身のMCPサーバーに対して回すが、その伝え方が違う。API経路は図面コンテキストと作図ルールをシステムメッセージで渡す。**Copilot CLIにはシステムプロンプト用のフラグが無い**ため、同じ内容を`# システム指示`の見出し付きでプロンプトの先頭へ前置し、MCPサーバーはそのセッション限定の一時設定ファイルとして渡し、GitHub標準のMCPサーバーは無効化し、`AGENTS.md`等のカスタム指示は読ませない。**Gemini**はJSON SchemaのOpenAPI部分集合しか受け付けないため、ツールのスキーマは許可されるキーだけに削って送る。**OpenAI互換**ではツール失敗を`ERROR: `を前置して返す(OpenAIのツールメッセージには成否欄が無いため)。

**設定の手順**: 設定 > エージェント > プロバイダ で経路を選び、その欄(パス / URL / モデル)を埋めて**保存**し、**接続テスト**を押す。バッジにCLIのバージョン・接続先の到達可否・失敗の内容が出る。エラーは生のダンプではなく種類で表示する(キーが違う・レート制限・モデル不明・混雑・サーバー・リクエスト不正・ネットワーク)。

**キーの置き場所**: APIキーは伏せ字で入力し、**OSキーチェーン**(macOSキーチェーン / Windows資格情報マネージャー / LinuxのSecret Service)にだけ書く(サービス名`MadakeCAD`、アカウント名は表のとおり)。`~/.madakecad/settings.json`にもプロジェクトファイルにもログにもエージェントイベントにも書かない — 設定ファイルにはそもそも項目が無い。各プロバイダ欄に保存/削除と「キー保存済み」バッジがあり、macOSでは許可ダイアログが繰り返し出ないようプロセスに1回だけ読み出す。CLI経路は何も保存せず、CLIが既に持っているサインインを借りる。

**接続先の差し替え**(テスト・社内ゲートウェイ用): `MADAKE_ANTHROPIC_BASE_URL` と `MADAKE_GEMINI_BASE_URL`。OpenAI互換経路はもともと設定欄のURLを使う。

> **上の表の「確認済み」の意味**。✅ = その経路で実際に作図の1ターン(編集 → 検証 → 報告、後始末にundo)を通した。🔶 = 有料の資格情報無しに観測できる範囲は確認済み(プロバイダ切替、伏せ字でのキー保存と削除、実エンドポイントがキー不正・キー無しを弾くこと、チャット内の案内、設定ファイルにキーが残らないこと)で、課金を伴う往復だけがユーザー確認事項。Copilotは未認証のまま作ったため、JSONLイベントの実形は寛容なパーサとフィクスチャで固めてあり実ストリームでは未確認。

## 整えバリアント(フェーズ4)

- 整えポップアップの**バリアント数**で「反復しない」の代わりに2・3・4を選んでモードを押す。表示中のシートが案の数だけ複製され(名前「<シート名> · 案A/B/C/D」、undo1回)、案ごとに別の会話が同じ整えプロンプトを並列に実行する(編集オーバーレイで全案の作業が同時に見える)。選択があれば各複製の対応する要素だけを整える
- **比較パネル**(下部ドック「整え案の比較」): 案ごとに状態・整え指標(交差 · 重なり · グリッド外と合計。元の図面と並べて表示)・「表示」(そのシートへ切替)・「この案を採用」が並ぶ。採用は全案が終わると押せる
- **採用**は選んだ複製の内容を**元のエンティティidのまま**元シートへ写し戻し(動かした要素は更新、案で消えた要素は削除、増えた要素は追加)、複製を全て消す。undo1回で戻る。**すべて破棄**は実行中の案を止めて複製を消す(同じくundo1回)。パネルを閉じても比較は続き、整えポップアップから開き直せる
- 自動化: `POST /api/v1/variants/start` `{sheet_id, count}`が複製とid対応表を返し、`POST /api/v1/variants/finish`(同じ内容+`chosen_sheet_id`またはnull)で採用/破棄。`GET /api/v1/tidy-metrics?sheet_id=`で任意のシートを測れる
