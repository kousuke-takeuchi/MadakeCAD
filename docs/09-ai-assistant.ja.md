# AIアシスタント

[English (canonical)](09-ai-assistant.md)

MadakeCADはアーキテクチャからAI-first: アシスタントは人間と全く同じCommand APIで図面を編集するため、AIの編集はすべてundo可能・リアルタイム描画・監査可能。

## 利用できる機能

- **アプリ内チャット**: 左ドックパネル+キャンバス上の浮きカード。ストリーミング応答。会話履歴はプロジェクトと一緒に保存
- **Claude Codeバックエンド**: ローカルのClaude Code CLIをヘッドレス実行し、既存のClaude Pro/Maxサインインを再利用(APIキー不要)。エージェントはMadakeCAD自身のMCPサーバーへ自己接続し、他のクライアントと同じツールを使う
- **Anthropic APIバックエンド**: **設定 > エージェント > プロバイダ**で「Claude Code CLI」(既定)と「Anthropic API」を切り替えられる。APIはMessages APIへ直接つなぐのでCLIのインストールは不要。APIキーは伏せ字で入力し、**OSキーチェーン**(macOSキーチェーン / Windows資格情報マネージャー / Secret Service。`MadakeCAD` / `anthropic_api_key`)に保存する — **設定ファイルにもプロジェクトにも書かない**。保存/削除・「キー保存済み」バッジ・モデル欄(既定`claude-sonnet-5`)・**接続テスト**ボタンを備える。どちらの経路も同じプロセス内MCPサーバーから同じツールを受け取るため、API経由の編集もCommandエンジン・undo履歴・リアルタイム描画を通り、チャットの見え方も変わらない。APIのエラーは種類ごとに表示する(キーが違う・混雑・レート制限・モデル不明・サーバー・リクエスト・ネットワーク)。接続先は`MADAKE_ANTHROPIC_BASE_URL`で差し替えられる(社内ゲートウェイ・テスト用)
- **GitHub Copilot CLIバックエンド**: **設定 > エージェント > プロバイダ**で「GitHub Copilot (Copilot CLI)」を選ぶと、このPCの`copilot`コマンドを非対話(`-p`・JSONL出力)で実行する。認証はCopilot自身のGitHubサインインに任せ、**MadakeCADはGitHubのトークンを保存しない**(`copilot`を起動して`/login`、または`GITHUB_TOKEN`等の環境変数)。図面の編集は同じくMadakeCAD自身のMCPサーバー経由で、そのセッション限定の一時設定ファイルとしてCopilotへ渡す(GitHub標準のMCPサーバーは無効化する)。Copilotにはシステムプロンプト用のフラグが無いため、図面コンテキストと作図ルールは`# システム指示`の見出しを付けてプロンプトの先頭へ前置する(`AGENTS.md`等のカスタム指示は読ませない)。設定画面には検出バッジ(CLIのバージョン表示)・モデル欄(`auto`ならCopilotが選ぶ)・実行ファイルのパス欄・**接続テスト**ボタンがある。未認証のときはチャットにその旨と`copilot`→`/login`の手順を表示する
- **ツールの透明性**: 各ツール実行を会話内チップで表示(✓ place_symbol …)、「適用済み rev N」を記録
- **安全なターン巻き戻し**: 各ターンには安定したターンID、各履歴エントリには編集origin(user / agent / mcp)が付く。「このターンを元に戻す」は**エージェントの編集だけ**を逆適用するため、ターン中・ターン後の手編集は残る。手編集で逆適用できなくなった場合(対象が消えている等)は、途中まで戻さずターンをそのままにして衝突を報告する。巻き戻し自体も通常の履歴エントリなので、undoで取り消せる。**並列会話での粒度**: 編集の由来は「エージェントか否か」までしか分からない(MCPの入口が会話を名乗らない)ため、別の会話のターンと編集が混ざった区間を戻すと**両方のターンがまとめて戻る**。巻き込まれたターンも巻き戻し済みとして扱い、「適用済み」表示のまま空振りする「元に戻す」を残さない
- **検証ループ**: 図面を編集したらエージェントは必ず`run_verification`を実行し、エラーが残れば直して再検証する(最大3回)。最終応答には必ず「検証: エラー0・警告1」の形で件数を書く。3回で消えないエラーは、いじり続けずに残っている指摘と原因を説明する
- **規格知識**: 編集可能なMarkdownノート(`resources/knowledge/standards.md`)を毎ターン注入 — JIS C 0617記号の使い分け、参照記号の接頭辞、線色/sqの慣習と許容電流、線番・ハーネスの決まり、グリッドとレイアウト、標準の作図手順、各診断コードの読み方。「図面の自動読み取り」がOFFでも規格知識は必ず載る。**設定 > エージェント > 詳細設定 > 知識ファイル**で自社のMarkdownを後ろに追記でき、後勝ちで上書きできる
- **出典付きのドキュメント回答**: `docs/`の目次をエージェントへ渡し、操作方法・規格・対応状況の質問には**推測せずファイルを読んでから**答え、出典を書くよう指示している(例: `出典: 05-wire-management.ja.md`)。未対応の機能はロードマップで「M4で対応予定」と答える(創作しない)
- **設計レビューと検証計画**: 「レビューして」で`run_verification`の決定的な指摘と、人が見ないと分からない5観点(参照記号の体系・線色/sqの慣習・ラベル命名・レイアウト・図枠情報)を1つの指摘一覧(重要度順)にまとめる。修正は提案までで、承認後に実行する。「動作確認手順を作って」には操作→期待結果の手順表で答える
- **部品選定**: `search_parts`を根拠に比較表(最大10件。定格・価格・購入先と「現行品との差分」列)と代替提案を返す。配置済み部品の置換は提案までで、実行は承認後
- **開始テンプレート**: 同梱3種(24V制御基本・モータ起動回路・非常停止回路)は**履歴1エントリ**として適用されるため、undo一発でまるごと戻る。リボン「プロジェクト」タブ・部品挿入グループ・エージェントの`list_templates`/`apply_template`から使え、`~/MadakeCAD/templates/*.json`で自作テンプレートも追加できる
- **整えポップアップ**: チャット入力欄の杖ボタンで「自動で整える」を開く — **配置整理 / 配線整理 / ラベル整頓**。モードを押すと普通のターンが1回送られ、そのプロンプトが「`get_tidy_metrics`で測る(配線の交差数・ラベルの重なり・シンボルの重なり・グリッド外の点)→ 直す → もう一度測る」を指示する。**改善が止まったら、または3回**で終え、最後にビフォー/アフターの数値を報告する。1回の整え=1ターンなので、**undo一発でまるごと戻せる**。選択があればその要素だけが対象(「これ以外は動かさない」)、選択が無ければシート全体。ポップアップを使わず言葉で頼んでも同じループを回す(規格知識にルールが入っている)。整えでは接続を変えない・部品を足したり消したりしない・文字を書き換えない
- **並列会話**: 複数の会話を同時に走らせられる。1つ目が答えている途中でも、別の会話へ切り替えれば送信できる(同じ会話の中は従来どおり1ターンずつで、送信ガードは**開いている会話**にだけ効く)。会話には開始順に4色のパレットから色が割り当てられ、キャンバスの**編集オーバーレイ**、会話一覧の行ドット・スピナー、タブ行の「N会話実行中」バッジで同じ色を使う
- **編集オーバーレイ**: エージェントの編集領域をキャンバス上でパルス表示(会話ごとの色)。AIがどこを触っているか常に見える
- **図面コンテキスト**: ターン開始時に現在シートの要約(シート・ネット・検証サマリ=エラー/警告/情報の件数と重要度順の先頭数件)をエージェントへ供給
- **キャンセルの安全性**: エージェントイベントにターンseqを付け、キャンセル済みターンの遅延イベントは破棄する(次の会話へ紛れ込まない)

2つ以上の会話が同時に走っている間は、ツール呼び出しではなく図面patch由来のハイライトだけ既定色で描く(patchはどの会話の編集かを持たないため)。

> **GitHub Copilotで確認できている範囲**。Copilot経路はCopilot CLI 1.0.80に対して**未認証のまま**作った: 起動フラグ一式が実機CLIに受け付けられること、MCP設定ファイルの形が`copilot mcp add --transport http`の書き出しと一致すること、未認証エラー(`No authentication information found.`)を検知して`/login`の案内を出すこと、までを確認済み。**JSONLイベントの実形はフィクスチャと寛容なパーサで固めてあり、実ストリームでは未確認**。サインイン(`copilot`→`/login`)後の実イベント形の確認と、作図の通し1ターンは**ユーザー確認事項**として残している。

> **Anthropic APIで確認できている範囲**。API経路は実キー無しの範囲で確認済み: プロバイダ切替、ダミーキーの保存(伏せ字表示+「キー保存済み」バッジ)、本物のエンドポイントからの401を「APIキーが受け付けられませんでした」と表示、キー削除、キー未設定のまま送信したときのチャット内の案内、設定ファイルにキーが残らないこと。**実キーでの通し確認(ツール往復を伴う作図)はユーザー確認事項**として残している。
