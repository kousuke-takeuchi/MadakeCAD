## 2. 新たに見つかった抜けと処置

1. **2D盤レイアウト** — ACADEの中核成果物(筐体レイアウト・DINレール・ダクト)。従来はFreeCAD 3D(M5-3)経由のみだった。**処置: M4仕様に§8(ネイティブ2D盤レイアウトシート)として追加。FreeCADとの同期はM5-3のまま**
2. **図枠・表題欄テンプレート** — 現状ハードコード。ベンチマークは自社様式に対応でき、OSS普及の前提でもある。**処置: M4仕様に§9として追加**
3. **プロジェクト内検索・ジャンプ**(参照記号で検索してシート間移動)。**処置: M4仕様に§10として追加(小粒)**
4. **IEC 81346構造指定子**(`=`機能・`+`場所・`-`機器) — EPLANの構造化の背骨。**処置: 長期のG1ロードマップ項目として記録(M4後、IEC様式対応と合わせて再検討)**
5. **DWG/DXFエクスポート** — AutoCAD系レビュアーへの受け渡しに有用。**処置: M6以降のバックログ候補(主要ワークフローはPDFで足りる)**
6. **単線図** — 配電系統図的表現。**処置: 当面スコープ外を明示(本ドメインは制御配線図)。需要があれば再検討**
7. **自動配線補助** — EPLANは整列シンボルを自動接続。**処置: UXバックログ。AI整頓(M3)が一部を代替**

## 3. ドキュメント整合性の指摘と解消

| 指摘 | 解消 |
|---|---|
| `docs/features.md` §10がA〜D方向の旧提案のままで、M2〜M6と二重化 | §10を`docs/specs/`への参照に変更 |
| マスタースペック§6のフェーズ計画がフェーズ0〜3を未来形で記述 | 履歴として注記し、マイルストーン(requirements §2)を正とした |
| 表示クラス: M2で線番(場合によりハーネス)クラスが7個から増える | m2仕様に注記。UI文言の同期に注意 |
| 公開用機能ドキュメントと仕様の同期 | 同一ソース(機能インベントリ+仕様)から記述し、計画項目には必ずマイルストーン表記 |

## 4. 結論

§2の処置を適用した結果、意識的に見送った項目(単線図・DWG連携・マルチユーザー。いずれも理由を記録)を除き、M2〜M6の仕様はベンチマークの必須機能を網羅している。逆にベンチマークに無い差別化点は: ngspice実解に基づく検証、ターン単位undo付きAI-first作図、完全スクリプト化可能なCommand API。
