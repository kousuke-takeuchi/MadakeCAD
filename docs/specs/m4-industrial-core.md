# M4 機能仕様: 産業CAD中核機能

対応する柱: G3(ベテラン品質)。**AutoCAD Electrical(ACADE)・EPLAN Electric P8をベンチマーク**とし、ベテランの実務に必要な中核機能を揃える。

参考: [ACADE機能(Autodesk)](https://www.autodesk.com/jp/products/autocad-plus/included-toolsets/autocad-electrical) / [ACADE製品特長(大塚商会)](https://www.cadjapan.com/products/items/autocad_electrical/point.html) / [EPLAN Electric P8](https://www.eplan-software.com/solutions/eplan-electric-p8/) / [EPLAN P8 Performance Description](https://www.eplan.com/content/dam/eplan/corporate/performance-descriptions/2024/en/performance-description-eplan-electric-p8.pdf)

|---|---|---|---|---|
| 線番自動採番(連番/参照ベース) | ✅ | ✅ | ⬜ | M2で連番、参照ベースは§6 |
| 端子台管理・端子台チャート | ✅ | ✅(端子台ごとの結線図) | 🔶 貫通端子まで | §1 |
| 回路の再利用(回路コピー/マクロ) | ✅ | ✅(マクロが中核) | ⬜ | §2 |

## 1. 端子台チャート

- **端子台ごとの結線表**: 端子番号 / 内部側接続先(参照記号:ピン) / 外部側接続先 / 線番 / 電線(色・sq・品番) / ジャンパ。ネットリスト+線番から自動導出
- 出力: CSV+図面シートとしての自動生成(1端子台=1表。EPLANの端子図に相当)
- ジャンパ(隣接端子の短絡バー)のデータモデル追加: `SymbolInstance.attrs["jumpers"]="1-2,3-4"`等(デザインフェーズで確定)

受け入れ基準: TB1(8極)の結線表が、図面の結線・線番と完全一致した状態で自動生成される。

## 2. 回路マクロ(回路の保存・再利用)

- 選択範囲を**回路マクロ**として保存(エンティティ断片+相対座標のJSON。`~/.../MadakeCAD/macros/`)
- 挿入時: 参照記号を自動再採番(R1→R5等)、線番はクリアして再採番対象に、配置プレビュー付き
- リボン「回路コピー」(既存todo)を「マクロ保存/挿入」に発展。プロジェクト内コピペ(⌘C/V)も同機構で実装
- AI連携: マクロはテンプレート(M3)と同形式にし、エージェントも挿入可能に

受け入れ基準: モータ回路一式をマクロ保存→別シートへ2回挿入で、参照記号が重複せずERCが通る。

## 3. PLC I/O

- **PLCモジュール定義**: 部品DB拡張(モジュール型番・点数・アドレス体系)。動的シンボル`plc_di_{n}p`等の追加
- **I/O割付表**: アドレス/信号名/接続先のテーブル(プロジェクト内保存)。表からのPLC図面自動生成(ACADE方式)とI/Oレポート出力
- 図面⇔割付表の双方向同期(図面の結線変更がレポートに反映)

受け入れ基準: 16点DIモジュールの割付表を入力→ラダー外形のI/O図面ページが自動生成され、I/Oレポートに接続先参照記号・線番が載る。

## 4. コイル⇔接点クロスリファレンス

- 同一参照記号のリレー(コイルK1と接点K1群)を関連付け、**コイルの下に接点の所在(シート-ゾーン)一覧**、接点脇にコイル所在を自動描画
- 接点数超過の検証(部品DBに接点構成を持たせ、使用数>実装数でERC Error)

## 5. 帳票群の拡充

| 帳票 | 内容 |
|---|---|
| From-Toワイヤリスト | 電線リストを「From(参照:ピン) / To / 線番 / 色 / sq / 長さ / 品番 / ハーネス」に拡張 |
| ケーブル一覧 | 多芯ケーブル(将来のCableエンティティ)単位の集計 |
| 端子台チャート | §1 |
| クロスリファレンス表 | ネット/リレーの参照一覧 |
| BOM拡張 | 部品DBからメーカ・価格・購入先を引き当てて列追加 |

出力形式: CSVに加えて**図面シート化**(表を図枠付きページとして出力)とPDF一括出力(表紙+回路+帳票)。

## 6. 参照ベース線番・ゾーン連動(M2の発展)

- 線番を図面アドレス由来(例: シート2ゾーンB3起点→「2B3」系)にするモード。ACADEの参照ベース採番に相当

## 7. シンボルエディタ

- SymbolDef(JSONプリミティブ+ピン)のGUIエディタ: グリッド上で線/円/矩形/テキスト/ピンを編集し、ユーザーライブラリ(`MadakeCAD/symbols/`)へ保存。部品挿入ダイアログに「ユーザー」カテゴリ追加
- 当面はJIS記号の不足分を追記する用途(コンタクタ・遮断器・変圧器・センサ類)。**同梱ライブラリ自体の拡充も本仕様に含む**(JIS C 0617の主要記号を50種程度へ)

## デザイン対象(M4全体)

- 端子台チャート(図面シート版)のレイアウト
- マクロ保存/挿入ダイアログ、挿入プレビュー
- PLC I/O割付表エディタ、PLC図面ページの様式
- クロスリファレンス表記(コイル下の接点表)
- 帳票シートの様式一式
- シンボルエディタ画面
- リボン「パネル」「レポート」「管理」タブの中身(現在プレースホルダ)
