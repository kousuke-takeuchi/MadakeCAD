# 画面設計書

作成: 2026-08-21。**ビジュアルの正は`MadakeCAD.pen`**(Pen.appで開く。暗号化のためRead不可、pencil MCPツールで読む)。
本書は画面の一覧・構成・実装対応表。共通ルールは[デザインシステム](design-system.md)。

## デザインワークフロー(必須)

1. 新しい画面・UIは先に`MadakeCAD.pen`でデザインする(design-first)
2. 足りない共通部品は「デザインシステム - 共通コンポーネント」ボードへ先に追加し、`design-system.md`へ同時記載
3. デザイン確定後に実装。色はCSS変数(`src/App.vue`)と`src/canvas/theme.ts`のトークンのみ

## メイン画面の構成

```
┌─ タイトルバー(ロゴ・ファイル名・開く/保存) ────────────────────────────┐
├─ リボンタブ行(ホーム/プロジェクト/回路図/パネル/レポート/…/表示/管理) ─┤
├─ リボン本体(選択タブのグループ群。回路図: 配線|部品を挿入|編集|検証/レポート) ┤
├──────────┬───────────────────────────────┬──────────┤
│ 左パネル       │ 図面タブ(Sheet1 × +)                    │ プロパティ    │
│ [プロジェクト| │ ┌──────────────────────────┐ │ パレット      │
│  エージェント] │ │ キャンバス(ダーク作図領域)             │ │ (選択物の    │
│ ツリー/チャット │ │  グリッド・JIS図枠・エンティティ        │ │  参照記号・  │
│               │ │  クロスヘア・選択・エージェント枠       │ │  型番編集)   │
│               │ └──────────────────────────┘ │              │
│               │ [シミュレーション結果パネル(開時)]        │              │
│               │ [検証結果パネル(開時)]                   │              │
├──────────┴───────────────────────────────┴──────────┤
├─ ステータスバー(座標|グリッド/スナップ/直交トグル|ログ|ズーム|MCPポート) ┤
└─ 浮きチャットカード(左下。左ドック展開中は非表示) ──────────────────────┘
```

## 主要インタラクション規約

- **ツール**: 選択(既定)/配線(L)/配置。配置中はゴースト表示、`R`回転、`Esc`解除。配線はダブルクリック/Escで確定
- **キャンバス**: 中ボタン or Space+ドラッグ=パン、ホイール=ズーム、ドラッグ=移動、空白ドラッグ=矩形選択、`⌘Z`/`⇧⌘Z`
- **モーダル**: 背面スクリム+外側クリック/Escで閉じる(設定・部品挿入)
- **パネル**: 下部ドック型(検証・シミュレーション)は閉じるまで表示、行クリックで図面連動
- **未実装UI**: 表示したままにし、押すとステータスバーへ「未実装」をログ

## レスポンシブ・テーマ

- デスクトップ専用(最小想定 1280x800)。パネル幅は固定(左340/右260相当)
- ライトテーマのみ実装(CAD調トークン)。ダーク切替は設定UIのみ存在(未実装、features.md参照)
