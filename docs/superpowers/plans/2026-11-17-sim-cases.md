# Simulation Study Cases and Faults by Click Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Save named simulation study cases in the project, choose shorts and wire breaks by right click (stored by wire / pin), and edit attribute overrides next to the selected part.

**Architecture:** `Project.sim_cases` (format 27) edited only through two new Commands; the core turns a case's faults into deck elements; every simulate entry point accepts `case_id`; the front-end store keeps the selected case and edits it through `store.execute`; a pure module decides the right-click menu; the panel and canvas show the case.

**Tech Stack:** Rust (madake-core, madake-mcp, madake-cli, Tauri), Vue 3 + Pinia + TypeScript, Canvas2D, Vitest, ngspice.

**Spec:** `docs/superpowers/specs/2026-11-17-sim-cases-design.md`

## Global Constraints

- `FORMAT_VERSION` 26 -> 27; `Project.sim_cases` with `#[serde(default, skip_serializing_if = "Vec::is_empty")]`; old files load with no cases.
- Case names: trimmed, not empty, unique within the project (exact match after trim); otherwise `SetSimCase` is refused with `CoreError::InvalidCommand`.
- Faults by id only: short on `{ wire_id }` or `{ entity_id, pin }`; open on `{ wire_id }`. Short = 1 mΩ to node 0 at the wire's first point / the pin's point. Open = the wire gets no elements.
- Missing fault targets: skipped with a warning; never an error.
- "Normal" is not stored; adding a condition while "Normal" is selected creates "Case N" (first free N from 1) and selects it.
- All document edits through `Command` / `Engine::execute`; the store calls `useDocumentStore().execute(...)`.
- Tests are the specification: Rust `///` English + Japanese; Vitest `it("English")` with `// ja:`; `python3 scripts/gen_spec.py` after test changes.
- Colours from `src/canvas/theme.ts` and `src/App.vue` variables only; UI follows `MadakeCAD.pen` (Task 6 designs, user approves, Task 7 implements).
- Nothing from the confidential reference in tests, commits or docs; `python3 scripts/audit_confidential.py` before each commit; Japanese commit messages with a conventional prefix, no attribution trailer.

## Review Focus

- A case referring to a wire that was deleted later: simulation must still run (warning), chip shown as missing (Task 2 core test, Task 4 store test).
- Undo after editing a case from the panel: the panel and selected case follow the patch (Task 1 command test, Task 4 store test on `sim_cases_replaced`).
- Deleting the selected case falls back to "Normal" (Task 4).
- Renaming a case to a name that already exists is refused and reported, not silently merged (Task 1).
- Right click on empty canvas or with the panel closed shows no simulation menu (Task 5).

```rust
impl SimOptions {
    /// 計算ケースの条件を足す (直接指定した置き換えはケースより優先)。
    pub fn with_case(mut self, case: &crate::model::SimCase) -> Self {
        for s in &case.open_switches {
            if !self.open_switches.contains(s) {
                self.open_switches.push(s.clone());
            }
        }
        for (r, attrs) in &case.overrides {
            let slot = self.overrides.entry(r.clone()).or_default();
            for (k, v) in attrs {
                slot.entry(k.clone()).or_insert_with(|| v.clone());
            }
        }
        self.faults.extend(case.faults.iter().cloned());
        self
    }
}
```
