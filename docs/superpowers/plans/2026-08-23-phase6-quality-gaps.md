# MadakeCAD フェーズ6本体 (品質ギャップ G5〜G18 の解消) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 再現検証台帳(`docs/internal/specs/reproduction-gaps.md`)の残ギャップ(品質向上+軽微)を解消し、参考図面「以上」の表現力にする。必須ギャップG1〜G4・G9・G17・G19〜G21はフェーズ5/6先行で解消済み。

**共通ルール:** Command絶対原則・tests-as-spec+gen_spec・i18n(en/ja)・ドキュメントEN+JA同期・.mdkproj変更はformat_version。機密: 汎用名のみ。

## 設計決定

- **G10 図形エンティティ**: `Shape { kind: Rect|Line|Circle|Polyline, points, stroke: 色トークン, stroke_width_mm, fill: Option<色トークン>, dashed: bool }`。電気的意味を持たない純粋な作図要素(netlist/ERC/BOM対象外)。表示クラス「図形」(12クラス目)。リボン「回路図」に作図ツール
- **G11 筐体囲み**: G10のShape(dashed矩形+ラベル)で表現できるため**専用エンティティは作らず**、ハーネス流用をやめる指針に変更。ハーネスは電線グルーピング専用に戻し、筐体・強調枠はShapeで(電線リストのハーネス列が汚れる問題が解消)。名前ラベルはTextEntityで自由配置
- **G5 ジャンパバー描画**: 端子台の`attrs["jumpers"]`を回路図上に短絡バー(隣り合う端子の印の隙間を埋める太線。**両端の丸は付けない**)として描画。SVG+キャンバス共有。表示クラスは「シンボル」に含める
  - 両端の丸を付けない理由: 端子ピッチ5mm・印の半径1.8mmだと隙間は1.4mmしかなく、太いバーと見分けの付く丸を両方入れると端子番号に掛かってしまう。バーの端がどの端子のものかは印の縁そのものが示す
- **G6 多段端子台**: 動的シンボル`terminal_block_{n}p_{levels}l`(例 `terminal_block_8p_2l`)。レベル=段(1〜3)。ピン番号は`1a/1b`形式(段記号)。端子台チャート・接続図が段を列で表現(既にLv列あり=活用)
- **G7 リレー実機ブロック**: 新シンボルではなく**デバイス集約表示**で解決: 同一参照記号のコイル+接点群を1デバイスとして扱う既存機構(relay_xref)に加え、`attrs["device_block"]="true"`のコイルは実機外形(型番・接点構成つきの箱)で描画するオプション。分散配置(現状)と実機ブロック(新)を選べる
- **G8 ピングループ括弧**: `SymbolInstance.attrs["pin_groups"]="1-4:電源,5-8:信号"`でピン範囲に括弧+グループ名を描画(ブロックシンボル/端子台/コネクタ共通)。縦書きは行分割で近似(縦書きフォント制御は不採用)
- **G13 デバイス単位シート間参照**: 同一参照記号が複数シートに現れる場合、各所在に「(/2.B3)」形式の相互参照を自動描画(relay_xrefのコイル所在描画を一般化)。表示クラス「参照記号」に含める
- **G14 嵌合コネクタ対**: `attrs["mates_with"]="J12"`で対を宣言。ERC: 対の極数不一致=Warning、片側のみ=Info。電線リスト・From-Toに嵌合相手列。図面上は破線の接続線(短い)を自動描画
- **G15/G16 メタCommand**: `set_sheet_paper { sheet_id, size, orientation }`(既存図面の座標は保持、枠外要素はWarning診断。当初の`w, h`は実装時のルーリングで用紙サイズ+向きの型に差し替え)、`set_project_meta { name, drawing_no, company, … }`(表題欄バインドの供給元)
- **G18 From-To改善**: 片端がネットラベルの場合、**そのネットに繋がる他端の機器**を辿って`K1:A1`形式で表示(1対1でなければネット名のまま+備考)。既存の劣化を解消
- **G22 コイル所在の衝突回避**: 接点脇のコイル所在テキストを、配線注記と重なる場合は反対側/下方へ逃がす(既存の重なり回避パターンを流用)
- **G9残**: 電線品番の凡例ブロック(色+sq+品番の表を図面へ挿入=Shapeでなく専用の自動描画ブロック)とBOMの電線集約行
