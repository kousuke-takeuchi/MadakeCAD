# 部品データベース

[English (canonical)](07-parts-database.md)

全プロジェクトで共有するローカルファーストの部品マスタ(SQLite)。図面は型番で参照し、ファイル自体は自己完結を保つ。

## 利用できる機能

- **部品マスタ**: 型番(一意キー)・メーカ・名称・カテゴリ・既定シンボル(可変ピンID可)・定格電圧・定格電流・購入先URL・データシートURL・価格/通貨・備考。3Dモデル参照/取付情報/SPICEモデルの予約列
- **電線品番マスタ**: 線色+sq→電線品番、m単価
- **検索→配置**: 部品挿入ダイアログからDBを検索し、選択すると既定シンボルが「型番=value、定格電流=検証用属性」付きで配置される
- **スキーマバージョン管理**+自動マイグレーション。初回にサンプル(ダミー型番)を投入
- **どこからでも**: CLI(`madake parts`)、MCPツール(`search_parts`/`upsert_part`/`delete_part`)、REST(`/api/v1/parts`・`/api/v1/wire-parts`)。AIアシスタントが対話で登録・検索できる
- 既定の保存先: OSのアプリデータフォルダ(`MADAKE_PARTS_DB`で変更)
