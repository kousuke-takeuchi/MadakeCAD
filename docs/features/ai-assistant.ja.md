# AIアシスタント

[English (canonical)](ai-assistant.md)

MadakeCADはアーキテクチャからAI-first: アシスタントは人間と全く同じCommand APIで図面を編集するため、AIの編集はすべてundo可能・リアルタイム描画・監査可能。

## 利用できる機能

- **アプリ内チャット**: 左ドックパネル+キャンバス上の浮きカード。ストリーミング応答。会話履歴はプロジェクトと一緒に保存
- **Claude Codeバックエンド**: ローカルのClaude Code CLIをヘッドレス実行し、既存のClaude Pro/Maxサインインを再利用(APIキー不要)。エージェントはMadakeCAD自身のMCPサーバーへ自己接続し、他のクライアントと同じツールを使う
- **ツールの透明性**: 各ツール実行を会話内チップで表示(✓ place_symbol …)、「適用済み rev N」を記録
- **ターン単位undo**: 各ターンが生んだundo段数を追跡し、「このターンを元に戻す」=その回数のundo
- **編集オーバーレイ**: エージェントの編集領域をシアンのパルスで表示。AIがどこを触っているか常に見える
- **図面コンテキスト**: 現在シートの要約(ネット・検証状態)をエージェントへ供給

## 計画中(M3「AI-first作図」)

- **基盤強化**: ターン安定ID、編集origin(user/agent)追跡 — ターン巻き戻しが手編集を巻き込まない
- **規格知識**: JIS記号の使い分け・参照記号規則・配線慣習を注入し、**検証ループ**(編集後にERC/電気検証を自走して自己修正)
- **テンプレート**: 標準回路の雛形(24V制御回路・モータ起動など)をチャット/新規作成から
- **自動整頓**: 「配置整理/配線整理/ラベル整頓」の反復実行(収束判定付き、1パス=1 undo)
- **並列エージェント**: 複数会話の同時作業・比較案生成
- **マルチプロバイダ**: Anthropic API・OpenAI互換(Ollamaローカル含む)・Gemini。認証情報はOSキーチェーン(ファイル保存しない)
