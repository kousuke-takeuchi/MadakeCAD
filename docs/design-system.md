# MadakeCAD デザインシステム

メイン画面(CAD調ライトグレー+ブルーアクセント+ダーク作図領域)を正とする共通デザインルール。設定・チャット・ダイアログを含む**全UIはこのトークンのみを使用する**。ビジュアル版は`MadakeCAD.pen`の「デザインシステム - 共通コンポーネント」フレーム。実装は`src/App.vue`のCSS変数と`src/canvas/theme.ts`が唯一の定義箇所で、コンポーネント内に生の色コードを書かないこと。

作図領域の配線色は`src/canvas/theme.ts`の`wireColorScreen()`(黒背景用)と`madake-core/src/svg.rs`の`color_hex()`(白紙印刷用)の2表で管理。

## タイポグラフィ

- 見出し: Noto Sans JP 17/700(ダイアログ大見出しは22/700)
- パネル見出し: 11/600、セクション見出し: 11/600+letter-spacing
- 本文: 12〜13/400、補助: 10/400
- 数値・コード・座標・品番: JetBrains Mono 10〜12

## コンポーネント規約

- **カード**: 白 #FFFFFF / 枠 ribbon-line / 角丸 12。ダイアログ背景は ribbon-bg
- **プライマリボタン**: acad-blue 塗り+白文字、角丸 8。セカンダリ: 白+ribbon-line枠
- **トグル**: ON=acad-blue / OFF=#D1D5DB、40x23
- **ラジオ・チェック**: 選択色 acad-blue
- **入力欄**: #FAFAFA / ribbon-line枠 / 角丸 8〜9
- **タブ(設定)**: ピル型コンテナ+選択タブは hover-bg 塗り+枠。**タブ(リボン)**: 選択タブは ribbon-bg 塗り+acad-blue太字
- **バッジ**: ドット+文字、上記セマンティック色
- **ポップアップ**: 白 / 角丸 12 / シャドウ 0 6 18 #00000028
- **チャットパネル**(作図領域左下オーバーレイ): 折りたたみ 330x148 / 角丸 12 / `--shadow-panel`、展開 380x640 / 角丸 14 / `--shadow-panel-lg`。背景 ribbon-bg + ribbon-line枠
- **ユーザー発話吹き出し**: hover-bg / 角丸 12 12 4 12 / padding 8 12 / 12px
- **ツールチップ**(エージェントのツール実行行): input-bg / 角丸 7 / ribbon-line枠 / padding 5 9。✓=ok-fg、✗=err-fg、実行中=回転スピナー(ui-placeholder)。ツール名は`--mono-font` 10px、要約は 10px muted
- **状態バッジ**: ドット6px+10px文字。接続中=ok、未接続=無効(off)
- 未実装機能のUIは表示したままにし、操作時にコマンドラインへ「未実装」をログする

## 運用ルール

新しい画面のデザインは、必ず本書と`.pen`の「デザインシステム - 共通コンポーネント」ボードを先に参照して既存コンポーネントを再利用する。足りないものは**先にデザインシステムへ追加してから**画面で使用し、本書へ同時に記載する(ボードと本書は常に同期を保つ)。

## 禁止事項

- コンポーネント内への生色コードの直書き(トークン追加はこのファイルと`.pen`のDSボードを同時更新)
- 黒(#171717系)アクセントの使用(旧Pencil流。アクセントは常にacad-blue)
