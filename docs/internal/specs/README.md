## 各仕様書の構成

1. **目的**(ビジョンの柱G1〜G5との対応)
2. **ユーザーストーリー**
3. **機能仕様**(データモデル・Command・コアロジック・API露出。UIは要件レベルまで)
4. **デザイン対象**(次フェーズでPencilに起こす画面・部品の一覧)
5. **受け入れ基準**
6. **未決事項**(実装前にユーザー判断が必要なもの / デザインフェーズで決めるもの)
