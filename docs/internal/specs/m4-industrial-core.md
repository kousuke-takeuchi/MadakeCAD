## 1. 端子台管理(端子台エディタ+端子台チャート)

> **ステータス: 🔶 フェーズ1完了(2026-08-22)。** 実装済み = §1.1のうち行の導出表示・サドルジャンパ(生成/削除。`attrs["jumpers"]`を`update_entity`で書き換えundo可)・予備端子表示・端子台チェック(未結線/不正ジャンパ)・チャート/接続図の生成起点、および§1.2の両様式(チャート=CSV+図枠付き図面シート、端子接続図=外部左/内部右のグラフィカルページ)。**フェーズ2に残した項目**(モデル拡張が必要): 並べ替え・多段端子(レベル)・アクセサリ・部品割当・内外スワップ・図面へジャンプ・端子番号の自動採番・予備端子の挿入。計画=`docs/superpowers/plans/2026-08-22-m4-phase1-terminals-reports.md`

**ベンチマーク: EPLANの「端子台の編集」ダイアログ+ACADE Terminal Strip Editor。** 単なる一覧表ではなく、端子台を編集する専用グリッドエディタを設ける。

### 1.1 端子台エディタ(グリッド)

- 列(EPLAN準拠): 行 / 状態 / **外部側**ターゲット(参照:ピン) / 外部ケーブル・ハーネス / ジャンパ(外部) / **端子番号** / レベル(多段) / ジャンパ(内部) / **内部側**ターゲット / 内部ケーブル / 線番 / 電線(色・sq・品番) / 部品型番 / 配置(シート.ゾーン)
- 操作(ツールバー+右クリック):
  - **並べ替え**: 数値順 / 英数順 / ページ順(回路図の出現順) / 外部ケーブル順 / ジャンパ順。多段端子はグループを保って移動
  - **自動採番**(端子番号の振り直し)、**予備端子の挿入**、行の上下移動
  - **多段端子の生成/解除**(複数の回路図端子を1つの多段端子ブロックへ割当)
  - **ジャンパ**: サドルジャンパ(内部/外部)の生成・削除。データは`SymbolInstance.attrs["jumpers"]`(例 `"1-2,3-4"`)+ジャンパ種別
  - **アクセサリ**: エンドブラケット・仕切り・エンドプレートの追加(部品DBから選択、盤レイアウト・BOMに連動)
  - **内外スワップ**(接続点の内部/外部入替)、**図面へジャンプ**(Go to: 該当端子を選択+ズーム)
  - **部品割当**: 部品DBから端子ブロック型番を割当(多段・貫通・ヒューズ端子等の種別を持つ)
- 検証: 端子台チェック(未結線・重複番号・多段の欠番)

### 1.2 出力(2様式)

- **端子台チャート(表)**: 列=エディタと同一。CSV+図枠付き図面シート
- **端子接続図(グラフィカル)**: EPLANの端子図様式 — 中央に端子ストリップ、**外部側を左・内部側を右**に配置し、ケーブル/ハーネスはブラケットでまとめて品番を記載

受け入れ基準: TB1(8極・ジャンパ2箇所・予備1)のエディタ操作(並べ替え・採番・ジャンパ)がundo可能なCommandとして動作し、チャート表・接続図の両方が図面の結線・線番と完全一致した状態で自動生成される。

## 2. 回路マクロ(回路の保存・再利用)

> **ステータス: 🔶 フェーズ2完了(2026-08-22)。** 実装済み = 保存(選択範囲→Command列+相対座標化。基準点=選択範囲の左下ピンを自動決定)、`~/MadakeCAD/macros/*.json`への書き出しと一覧(壊れたJSONはissueとして報告)、挿入(UUID振り直し+参照記号の再採番(既存最大+1、マクロ内の関係は保持)+線番クリア。`execute_batch`で1編集=undo一発)、バリアントの列挙と選択(配置中`Tab`)、部品挿入ダイアログの「マクロ」タブ(カテゴリツリー+バリアント数バッジ+プレビュー)、保存ダイアログ、ゴースト配置(`R`回転・Esc・連続配置)、⌘C/Vの無名マクロ。露出=Tauri IPC(`list_macros`/`save_macro`/`apply_macro`/`open_macros_folder`)・Link API(`GET /macros`・`POST /macros/build|save|apply|apply-inline`)・MCP(`list_macros`/`save_macro`/`apply_macro`)。**フェーズ3に残した項目**: プレースホルダと値セット、保存ダイアログからのバリアント追加(UIはdisabledプレースホルダで示す)。計画=`docs/superpowers/plans/2026-08-22-m4-phase2-macros-xref-nav.md`
>
> **値セット: 🔶 フェーズ3完了(2026-08-22)。** マクロ形式へ`placeholders`(key+label(英/日)+行き先`{entity, field: "value"|"attrs.<名前>"}`)と`value_sets`(id+label(英/日)+`{key: 値}`)を追加(どちらも省略可・旧マクロJSONはそのまま読める)。挿入時に値セットidを渡すと、行き先の欄へ値が入った状態で`execute_batch`されるので**undo一発**のまま。知らない値セットid・宣言されていないキー・マクロに無い行き先は図面を変えずにエラー(部分適用しない)。UI=保存ダイアログの「プレースホルダ」表(選択範囲の型番欄・属性にキー名を付ける。同じキー名の欄は1つのプレースホルダにまとまる)+「値セット」表(名前+キーごとの値。idは名前から自動生成)、挿入ダイアログの値セットドロップダウン(値セットを持つマクロにだけ出る)。⌘C/Vの無名マクロには値セットが無い。露出=Tauri IPC(`apply_macro`/`apply_macro_inline`の`value_set`)・Link API(`POST /macros/apply|apply-inline`の`value_set`、`POST /macros/save`の`placeholders`/`value_sets`)・MCP(`apply_macro`の`value_set`、`save_macro`の`placeholders`/`value_sets`、`list_macros`の返却)。計画=`docs/superpowers/plans/2026-08-22-m4-phase3-library-valuesets-plc.md` Task 2

**ベンチマーク: EPLANのウィンドウマクロ(バリアント+プレースホルダ+値セット)。** ACADEの回路コピーも同機構で包含する。

- **保存**: 選択範囲+基準点(挿入時のカーソル位置)を指定してマクロ化(エンティティ断片+相対座標のJSON。`~/…/MadakeCAD/macros/`)
- **バリアント**: 1マクロに複数バリアント(A〜H)。挿入プレビュー中に**Tabで切替**(例: モータ回路の 直入れ/正逆転/スターデルタ)
- **プレースホルダと値セット**: マクロ内の可変値(定格・型番・信号名)をプレースホルダ化し、**値セット**(例: 0.75kW/1.5kW/2.2kW)を選ぶと関連する全シンボルの定格・部品を一括設定
- **挿入**: 部品挿入ダイアログの「マクロ」カテゴリ(ツリー+プレビュータイル、バリアント数バッジ)。挿入時に参照記号を自動再採番・線番クリア。配置プレビュー+R回転
- プロジェクト内コピペ(⌘C/V)も同機構。マクロはM3回路テンプレートと同形式でエージェントも挿入可能

受け入れ基準: 3バリアント+値セット付きモータ回路マクロを保存→Tabでバリアント切替して2回挿入→値セット選択で定格が一括設定され、参照記号が重複せずERCが通る。

## 3. PLC I/O

**ベンチマーク: ACADEの「Spreadsheet to PLC I/O Utility」+モジュールライブラリ。**

- **PLCモジュール定義**: 部品DB拡張(モジュール型番・点数・**メーカ別アドレス体系**: 三菱`X0/Y0`・Siemens`%I0.0/%Q0.0`・Allen-Bradley`I:0/0`)。動的シンボル`plc_di_{n}p`等
- **I/O割付表エディタ**: アドレス/信号名/接続先/線番/コメントのグリッド。Excel/CSVの読み込み・書き出し(信号名一括入力の実務フロー)。接続先・線番は図面から自動反映(読み取り専用)、信号名・コメントはここが正
- **図面自動生成(生成設定ダイアログ)**: ACADEのウィザード相当 —
  - ラダー: 縦バス+横ラング / 横バス+縦ラング、ラダー幅、1シートのラダー本数
  - ラング間隔、開始位置(先頭スキップ数)
  - モジュール配置方針: ①モジュールごとに新ラダー / ②収まる場合のみ前モジュールと同居 / ③同居し必要なら分割
  - 設定はプロジェクトに保存(再生成で再利用)
- 図面⇔割付表⇔I/Oレポートの双方向同期

受け入れ基準: CSVから16点DIの割付を読み込み→生成設定(1ラダー・ラング間隔10mm・分割許可)でI/O図面ページが自動生成され、結線変更が割付表とレポートに反映される。

## 4. クロスリファレンスとナビゲーション(コイル⇔接点・Surfer)

> **ステータス: ✅ フェーズ2完了(2026-08-22)。** 実装済み = 同一参照記号のコイル+接点群=1デバイス(`relay_xref.rs`)、接点の読み順(シート番号→ゾーン→id)による端子対の割当(IEC 60947-1。コイル=A1-A2)、コイル外形下端+2.5mmの接点マップ(端子対|所在。`contact_config`が読めるとき未使用は「—」)、接点の外形右端+1mmのコイル所在、キャンバス/SVGの同一数式(`contact_map_layout`/`contactMapLayout`)、ERC 4種(`contact_overflow`=Error / `orphan_contact`=Error / `coil_without_contact`=Warning / `invalid_contact_config`=Warning)、部品DBの`contact_config`(スキーマv3。配置時に`attrs`へ写す)、シンボル`relay_contact_nc`の追加、参照サーフィン(キャンバスでAlt+クリック→所在一覧→↑↓/Enterで巡回)。**残り**: 表現形式(表/グリッド)の図枠テンプレート側選択(§9と同時)

- コイル下の**接点マップ**(端子対+所在「/シート.ゾーン」の表)+接点脇のコイル所在を自動描画。表現形式(表/グリッド)は図枠テンプレート側で選択
- 接点数超過の検証(部品DBに接点構成を持たせ、使用数>実装数でERC Error)。**例外レポート**: 親の無い接点・接点の無いコイル(ACADEのException report相当)
- **参照サーフィン(ACADE Surferに相当)**: XRefラベル・参照記号・線番をクリック→関連要素(同一デバイスの全所在・ネットの相手先)を一覧ポップアップで巡回ジャンプ。検索(§10)と同じreveal機構

## 7. シンボルエディタ

**ベンチマーク: ACADE Symbol Builder+EPLANシンボルエディタ。**

- **図形+属性プレースホルダ**: シンボル定義は図形プリミティブに加えて**属性スロット**(参照記号TAG・説明・型番/メーカ・定格・端子番号ラベル等)の位置・スタイルを持ち、配置時に実値が流し込まれる(ACADEのTAG1/DESC/MFG/CAT属性に相当)。`SymbolDef.text_slots`を追加
- **ピン(接続点)**: 番号+**接続方向**(上/下/左/右 — 配線の自動接続・引き出し方向に使用)+名前/説明(ACADEのX?TERM##方向付き接続属性、EPLANの接続点ロジックの簡略版)。必ず2.5mmグリッド上
- **回転バリアント**: EPLANは1シンボル最大8バリアント(A〜H)を持つ。MadakeCADは0/90/180/270を自動生成し、接続点番号・属性位置の追従を既定にして、変になる向きだけ手動上書き
- **ファミリ・命名**: 参照接頭辞(K/PB/F…)・カテゴリ・検索キーワード。既存シンボルを複製して開始する流儀(ACADEチュートリアル方式)を既定動線に
- **ライブラリ管理**: 同梱ライブラリ(JIS C 0617主要50種へ拡充)+ユーザーライブラリ(`MadakeCAD/symbols/`)。部品挿入ダイアログに「ユーザー」カテゴリ
- 検証: ピンのグリッド外・番号重複・必須属性スロット欠落を保存時チェック

受け入れ基準: コンタクタ3Pを既存シンボル複製から作成(ピン6+TAG/定格スロット)→4方向バリアント自動生成→配置・配線・BOM・SVG出力まで既存シンボルと同等に動く。

## 8. 2D盤レイアウト(ギャップ分析 2026-08-21で追加)

**ベンチマーク: ACADEのパネルレイアウト。** 盤レイアウト専用シート種別を追加する。

- **フットプリント**: 部品DBの外形寸法(W×H×D)から簡易矩形+参照記号で生成(カタログルックアップで型番→寸法)。回路図の部品一覧から「未配置部品」をドラッグ配置(EPLANのナビゲータからの配置に相当)
- **DINレール・ダクト**: 専用エンティティ。レールへのスナップ配置、レール充填率の表示、部品間隔チェック(放熱クリアランス)
- **フットプリントルックアップ**: 型番(メーカ+カタログ番号)→フットプリント定義の対応表(ACADEのfootprint lookup DB相当)。部品DBに`footprint_ref`を追加し、未登録型番は寸法から簡易矩形を自動生成。**挿入経路は3つ**: ①回路図部品リスト(未配置部品パネル) ②アイコンメニュー(回路図に無い盤部品: レール・ダクト・盤筐体等) ③型番検索
- **配線注記(盤内配線図)**: 回路図の結線データからフットプリント脇に接続先・線番を自動注記し、盤内配線図として出図できる(ACADEのwire annotation相当)
- **凡例・寸法**: バルーン↔型番の凡例表を盤シートへ自動配置。寸法線・取付穴(M5では3D筐体と同期)
- **バルーン(アイテム番号)**: 部品に連番のアイテム番号を振り、バルーン(円/多角形)を自動配置。BOMのアイテム番号列と連動
- **銘板(ネームプレート)**: フットプリントに銘板を関連付け、銘板一覧レポートを出力
- 帳票: 盤内部品配置表(アイテム番号/参照記号/型番/位置)。FreeCADの3D筐体との同期はM5-3

受け入れ基準: 回路図の全部品を盤シートへ配置(未配置ゼロ)→バルーン自動採番→配置表とBOMのアイテム番号が一致する。

## 9. 図枠・表題欄テンプレート(ギャップ分析 2026-08-21で追加)

**ベンチマーク: EPLANプロットフレーム+ACADEタイトルブロック機構。**

- **テンプレート=プロットフレーム**: 枠図形+**プロパティプレースホルダ**(特殊テキスト)で構成。プロジェクト/シートのプロパティ(プロジェクト名・図番・シート番号/総数・改訂・作成/承認者・日付・尺度・会社名)を`{project.name}` `{sheet.no}/{sheet.total}`のようなバインドで配置し、描画時に実値が入る(EPLANのplaceholder texts、ACADEのWD_TB属性マッピングに相当)
- **ゾーン設定**: 列数・行数・ゾーン文字(数字/英字)・目盛線をテンプレート側で定義(EPLANのrow/column texts)
- **表題欄**: セル罫線+フィールドバインド+自由プロジェクト変数(ACADEの複数行説明DESC1..3相当)。**ロゴ画像枠**(PNG/SVG埋め込み)対応
- **改訂欄**: 位置・行数・成長方向(下から上)をテンプレートで定義(M2改訂欄と連動)
- **一括適用**: テンプレート差し替え・変更時に全シートへ一括反映(ACADE Title Block Update相当)。プロジェクト/グローバルの2階層

## 10. プロジェクト内検索・ナビゲーション(ギャップ分析 2026-08-21で追加)
