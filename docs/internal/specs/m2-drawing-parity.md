# M2 機能仕様: 参考図面の完全再現

対応する柱: G1(規格準拠)・G3(ベテラン品質)。品質基準はユーザー提供の参考図面(社外秘)。

## 1. 改訂欄(リビジョンテーブル)

### 目的
JIS図枠の必須要素。データモデル(`Sheet::revisions: Vec<Revision {mark, date, description, by}>`)は既存だが、描画と編集UIが無い。

### 仕様
- **描画**(svg.rs+renderer.ts の両方、同一ルール): 図枠内に改訂表を描く。列=記号/日付/内容/担当。行は下から積む(JIS慣習)か参考図面の並びに合わせる
- **表題欄のrevとの連動**: 最新改訂の`mark`を表題欄のRev表示に反映
- **編集**: 改訂行の追加・編集・削除。Commandは既存の`set_revisions`系がなければ`update_sheet`拡張または`set_revisions`を新設(逆コマンド=旧リストの復元)
- **AI**: `execute_commands`経由で自動記入可(例: 「改訂Bを追加して: 内容=モータ回路追加」)

### デザイン対象
- 改訂欄の図面上の配置・寸法(参考図面準拠。.penの図枠デザインへ追記)
- 改訂欄編集UI(プロパティパネル拡張 or 専用ダイアログ)

### 受け入れ基準
- 改訂を2行追加するとキャンバス・SVG・PDFの3か所に同一の表が出る。表題欄Revが最新markになる
- undoで行追加が戻る

### 未決事項
- [x] 様式は**AutoCAD Electrical / EPLANの慣行に準拠**(2026-08-21ユーザー決定)。改訂欄は表題欄の直上に下から積む(ISO 7200系の一般形)。列=記号/日付/内容/承認
- [ ] 行数上限と溢れ時の挙動(古い行を省略?別紙?)— デザイン時に決定

## 2. 線番(ワイヤ番号)

### 目的
参考図面の中核表現。電線1本ごとの識別番号で、端子台結線・電線リスト・現物マーキングを対応付ける。ACADE/EPLANの中心機能(自動採番+参照ベース番号)。

### 仕様
- **データ**: 線番は**ネット単位**の属性。既存`Wire::net: Option<String>`を線番の保存先として正式化(同一ネットの全Wireへ同値を書き込む)。手動指定はネットラベルと同様に優先
- **自動採番**: 新Command `renumber_wires { sheet_id, mode }`。mode=連番(既定: 1から、参考図面の桁数/書式は設定)または参照ベース(ゾーンアドレス由来。将来)。採番済み・ラベル付きネットは保持し、未採番のみ振る「追い番」と、全振り直しの両モード
- **表示**: 各ネットの代表位置(最長ワイヤ線分の中点)に線番テキストを描画。表示クラス「線番」を追加(8クラス目)。SVG/PDFにも出力
- **帳票連動**: 電線リストCSVに線番列を追加。ネットリスト/検証の`Net.name`は線番を優先表示
- **UI**: リボン「配線」グループの「線番挿入」(既存todoボタン)を「自動採番」+「線番編集(クリックで個別編集)」に

### デザイン対象
- 線番テキストの見た目(サイズ・囲み有無・引出線の要否。参考図面準拠)
- 自動採番ダイアログ(開始番号・書式・追い番/振り直し)

### 受け入れ基準
- 自動採番後、全ネットに一意の線番が付き、画面・PDF・電線リストが一致する
- 個別編集した線番は再採番(追い番モード)で保持される

### 未決事項
- [x] **ACADE準拠**(2026-08-21決定): 既定は連番(開始1・桁数設定可)、参照ベース採番はM4。配置はネットごとに代表1箇所+設定で全ワイヤ表示
- [ ] プレフィックス等の書式オプションの詳細 — デザイン時に決定

## 3. ハーネス境界(破線囲み)

### 目的
参考図面の表現。ハーネス(ケーブル束)としてまとめて製作・購入する範囲を破線で囲み、名前を付ける。

### 仕様
- **データ**: 新Entity `Harness { id, points: Vec<Point>(閉じた多角形または矩形), name, note }`。`kind: "harness"`
- **所属判定**: ワイヤの**幾何学的内包**(全点が囲み内)で自動判定し、電線リストにハーネス列を追加。明示割当は将来
- **描画**: 破線ポリゴン+名前ラベル(左上)。表示クラス「ハーネス」追加または「注記」に含める(デザインで決定)
- **編集**: 矩形描画ツール(リボン「配線」グループへ)、頂点編集は将来
- **Command**: 既存add/update/remove_entityで扱えるようEntity追加のみ

### デザイン対象
- 破線スタイル・ラベル位置(参考図面準拠)
- 作図ツールのUI(リボンボタン+ドラッグで矩形)

### 受け入れ基準
- ハーネス矩形を描くと内包ワイヤの電線リストにハーネス名が付く。SVG/PDFに破線と名前が出る

### 未決事項
- [x] **矩形で開始**(2026-08-21決定・ACADE/EPLANのlocation box相当)。多角形は需要が出たら
- [ ] ハーネス単位の帳票(ハーネスごとの電線表)はM2かM4か

## 4. シート間クロスリファレンス

### 目的
複数シート図面で、同名ネットラベルがどのシート・ゾーンへ続くかを図面上に示す(ACADEのリファレンス表記相当)。

### 仕様
- **ネットリスト拡張**: `extract_netlist_project(project)`を追加し、同名ラベルを**シート横断**で統合(検証・帳票もプロジェクト全体ネットに対応)
- **参照表示**: ネットラベルの脇に相手先アドレス「→ 2-B3」(シート番号-ゾーン)を自動描画。相手が複数なら列挙。ゾーンは座標から算出(既存zone_cols/rows)
- **シート番号**: `Sheet`に表示順(現状Vec順)を使用。表題欄に「シート n/N」は既存
- **検証**: `erc.label_conflict`等をプロジェクト全体で評価するオプション

### デザイン対象
- 参照アドレスの表記(書式・フォント・位置。参考図面/ACADE慣習)

### 受け入れ基準
- シート1の「24-P1」ラベルにシート2の該当ゾーンが表示され、シート2側にも逆参照が出る。PDFにも出力
- シートを跨いだネットが電線リスト・検証で1ネットとして扱われる
