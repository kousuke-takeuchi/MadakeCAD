# MadakeCAD デザインガイドライン

Apple HIGに相当する、MadakeCAD全UIの規範。**すべての画面・ダイアログ・パネルはこのガイドラインのFoundationsとコンポーネントだけで構成する。** ビジュアル版は`MadakeCAD.pen`の「デザインシステム - 共通コンポーネント」と「デザインガイドライン - Foundations」ボード。実装上の色・影の定義箇所は`src/App.vue`のCSS変数と`src/canvas/theme.ts`のみ。

## 1. デザイン原則

1. **図面が主役** — UIクロームは淡いグレーの脇役に徹し、彩度の高い色は作図領域・状態表示・アクセントに限る。作図領域はダーク(#212830)、紙面プレビュー・印刷は白
2. **CADの慣習に従う** — レイアウト・密度・操作感はAutoCAD Electrical / EPLANの利用者が迷わないこと(リボン、ドックパネル、ステータスバー、コマンドログ)。ただし図面上の記法はIEC/ISO/JIS規格を最優先
3. **高密度・小サイズ** — 業務ツールとして情報密度を優先。本文12px・ラベル11px・キャプション10pxを基準とし、装飾的な余白を取らない
4. **1つのスケール** — 色・字・余白・角丸は本書のスケール以外の値を使わない。迷ったら近い既存コンポーネントを流用する
5. **AIと人間は同じUI** — AIの編集も人間の編集と同じ見た目・同じフィードバック(選択表示、undo、パネル連動)で表示する。未実装機能もUIに見せ、操作時に「未実装」をログする

### 2.2 タイポグラフィ

フォント: Noto Sans JP(UI)/ `--mono-font` = JetBrains Mono → SF Mono → Menlo(数値・コード・座標・品番・線番)。

| 段階 | サイズ/ウェイト | 用途 |
|---|---|---|
| display | 22 / 700 | オンボーディング等の大見出し(稀) |
| title | 17 / 700 | ダイアログ見出し |
| section | 11 / 600 (+letter-spacing 0.5〜1) | パネル見出し・セクション見出し・ポップアップ見出し(10/600のことも) |
| body | 12 / 400〜600 | 本文・メニュー項目・タブ |
| label | 11 / 400〜600 | フォームラベル・リスト主要行 |
| caption | 10 / 400〜600 | 補助文・バッジ・リボン小ボタン文字・グループ名 |
| mono | 10〜12 | コード・数値。表中の数値は右寄せ |

**8px・9pxは使用禁止**(最小10px)。13pxはチャット本文のみ許容。行間はサイズ×1.4前後。

### 2.3 スペーシング

2pxグリッド。推奨ステップ: **2 / 4 / 6 / 8 / 10 / 12 / 16 / 24**。
- コントロール内padding: 小=2〜4、標準=6〜10、ダイアログ本体=16〜24
- 兄弟要素gap: 密=2〜4、標準=6〜10、セクション間=16〜24
- 標準コントロール高さ: リボン小ボタン=22前後、入力欄・ボタン=26〜28、リスト行=24〜32

### 2.4 角丸スケール

| 段階 | 値 | 用途 |
|---|---|---|
| micro | 2 | 12px以下の微小要素(色スウォッチ・チェックボックス)のみ |
| sm | 4 | **ボタン・入力欄・ドロップダウン**・チップ・小ボタン・ファイルタブ・リスト行・部品DB行 |
| md | 8 | ダイアログ外枠・メニュー項目・ツールチップ・ステッパー |
| lg | 12 | ポップアップ・浮きカード・吹き出し(チャット系のみ) |
| pill | 999 | バッジ・円形ボタン |

**この5段以外の角丸値は禁止**(3, 5, 6, 7, 9, 10, 11, 13, 16px等を新規に書かない)。2026-08-21改定: ACADE/EPLAN のデスクトップCAD様式に寄せ、ボタン・入力欄を8→4、ダイアログ外枠を12→8へ引き下げた(チャット・ポップオーバー系のみ12を維持)。

### 2.5 アイコン

lucideを使用。サイズ: リボン大=26、メニュー/パネル=14、リボン小・ツールチップ=13、状態ドット=6。色は`--ribbon-icon`(UI操作)、`--ui-muted`(非アクティブ)、状態色(セマンティック)。絵文字をUIアイコンに使わない。

## 3. インタラクション状態

すべての操作可能要素は次の状態を持つ。新規コンポーネントはこの表に従って全状態をデザインする。

| 状態 | 表現 |
|---|---|
| default | 透明背景 or card-bg |
| hover | `--hover-bg`(塗りボタンは明度-5%相当。カーソルpointer) |
| active/選択 | `--sel-blue`背景(+必要ならacad-blue枠 or 文字700)。アクティブタブ=acad-blue文字+下線2px |
| focus(入力) | 枠を`--acad-blue`に(入力欄のみ。ボタンへのfocusリングは現状なし) |
| disabled/未実装 | 文字・アイコン`--off-fg`。未実装は押せるままにし、操作時にコマンドラインへ「〜で対応予定」をログ |
| busy | 回転スピナー(`--ui-placeholder`) |

## 4. コンポーネント

- **カード**: card-bg / 枠 ribbon-line / 角丸 lg(チャット系)。ダイアログ背景は ribbon-bg
- **プライマリボタン**(DSボタン主): acad-blue塗り+白文字、角丸 sm、padding 5 14、高さ26。セカンダリ(DSボタン副): 白+ribbon-line枠、角丸 sm。**無効**(DSボタン主無効): 同じ寸法で off-bg塗り+off-fg文字(§3の disabled)。入力に指摘があるあいだ実行系ボタンをこれに差し替える(ピン表エディタ・端子台エディタのポップオーバー)
- **入力欄・ドロップダウン**: ダイアログ内=白+ribbon-line枠+角丸 sm+padding 5 8(値はmono 11)。チャット入力のみ input-bg/角丸 md
- **秘密入力欄**(DS秘密入力欄): APIキー等の資格情報用。入力中は`type="password"`の通常入力欄、保存後は**値を読み戻さず**`key-round`アイコン11px+伏せ字`••••••••••••••••`のmono表示に切り替える。右に保存/削除のセカンダリボタン。**保存先はOSキーチェーンのみ**(設定ファイル・ログ・イベントへ平文を出さない)。状態バッジは「キー保存済み」(ok)/「キー未設定」(off)
- **チェックボックス**(DSチェックON/OFF): 14x14 / 角丸 micro。ON=acad-blue塗り+白チェック、OFF=白+ribbon-line枠。**ダイアログ内のon/off設定はトグルでなくチェックボックスを使う(CAD慣習)**
- **ステッパー**: 外枠 input-bg+枠+角丸 md、[−]26x28 / 値枠 40x28(白+枠、mono 12/600中央)/ [+]26x28
- **トグル**: 非推奨(旧設定画面のみ。新規UIではチェックボックスを使用)
- **ラジオ・チェック**: 選択色 acad-blue。ラジオは16x16の丸、**選択**(DSラジオ選択)=acad-blue枠1.5+中央に8pxの塗り、**未選択**(DSラジオ未選択)=白+ribbon-line枠1.5。ラベルは11px、ドットとの間隔5
- **バッジ**: 状態ドット6px+caption文字、状態色bg/fg、角丸 pill
- **チップ**: hover-bg or 状態bg / 角丸 sm / caption
- **タブ(リボン)**: 選択=ribbon-bg塗り+acad-blue太字。**設定のカテゴリ切替はタブでなく左ツリー**(下記CAD調ダイアログ)。**タブ(左パネル)**: タブ行=palette-head / padding 0 6 / gap 2。タブ=padding 7 10 0+11px、非アクティブ=600 ui-muted、アクティブ=700 acad-blue+下線2px(非アクティブにも透明下線)。行右端に状態バッジ+履歴+最小化(エージェントタブ時)。**実行中バッジ**: 応答中の会話が1本以上あるとき、接続バッジの右に「N会話実行中」(sel-blue地 / acad-blue 600 / 回転する`loader-circle` 10px)を足す
- **リボン小ボタン(R小)**: アイコン13px ribbon-icon+文字10px、角丸 sm。トグル版=ON: sel-blue塗り+文字ui-text、OFF: 透明+ui-muted
- **リボン大ボタン**: アイコン26px(グループごとのアイコンアクセント色)+ラベル。アクティブ=sel-blue
- **ポップアップ**: card-bg / 角丸 lg / shadow-popup / 幅300(モデルピッカー240)、本体padding 10 8 / gap 2。見出し=10/600 letter-spacing 1 ui-placeholder。閉じる=外側クリック+Esc(`composables/popover.ts`の`usePopover`)
- **メニュー項目(ポップアップ行)**: padding 8 10 / 角丸 md / アイコン14+文字12、gap 9。hover=hover-bg
- **ツールチップ(ツール実行行)**: input-bg / 角丸 md / ribbon-line枠 / padding 5 9。✓=ok-fg、✗=err-fg、実行中=スピナー。ツール名=mono 10、要約=10 muted
- **左パネル(ドック)**: 幅340 / 全高 / ribbon-bg / 右境界ribbon-line。タブ内容は`v-show`常時マウント
- **下部ドックパネル**(検証・シミュレーション): ヘッダ=palette-head(タイトル11/600+件数バッジ+右端アクションacad-blue+閉じるX)。行クリックで図面連動(選択+ズーム)。閉じるまで表示
- **整え案の比較パネル**(M3フェーズ4。上記ドックパネル様式の再利用。`.pen`「M3デザイン - 整え案の比較パネル」): ヘッダ=タイトル+モードのinfoバッジ+元の図面の指標(10 muted)+右端「すべて破棄」リンク+閉じるX。行=会話色ドット8px+案ラベル11/600+状態pill(実行中=warn/完了=ok/送信失敗=err)+指標mono 10(元より良ければok-fg 600)+「表示」リンク+「この案を採用」(acad-blue枠の小ボタン。全案完了まではdisabled)。表示中の案の行=sel-blue。状態は3枚(比較中=実行中の案あり・採用ボタンdisabled+ヘッダにui-placeholderのヒント / 採用=全案完了・表示中の行sel-blue・送信失敗の案だけoff-fg枠のまま / 破棄=採用も破棄も1Command=undo一発で終わるとパネル自体が閉じる)。破棄の確認ダイアログは重ねない
- **モーダルダイアログ(CAD調)**: スクリム+中央カード(ribbon-bg / 角丸 md / shadow-panel-lg)、外側クリック/Escで閉じる。構成はEPLAN/ACADEのオプションダイアログに倣う(.pen「設定ダイアログ - CAD調リデザイン」が正):
  - タイトルバー=palette-head / padding 8 12 / 題12/600+閉じる✕
  - **左カテゴリツリー**=幅180 / palette-bg / 右境界ribbon-line。行=padding 6 14 / 12px、選択行=sel-blue塗り+600、非選択=ui-muted
  - **グループボックス**=見出し(11/600 ui-text)+右へ伸びる罫線1px ribbon-line、内容はその下にgap 9で並べる
  - **フォーム行**=ラベル(11px / 幅130固定・コロン付き)+コントロール+補助要素。説明はcaption 10 mutedをラベル幅分インデント

### M4フェーズ5 端子台エディタ ポップオーバー

`.pen`ボード「M4デザイン - 端子台チャート/帳票様式」(frame `JqOIZ`)の末尾に追加した面。M4仕様§1.1の積み残し8項目のうち、ツールバーから開く5つのポップオーバー(採番・予備端子の挿入・段数・部品割当・付属品)と、並べ替えドロップダウン・列見出しの状態バリエーション。計画=`docs/superpowers/plans/2026-09-28-m4-phase5-terminal-editor-leftovers.md`。ベンチマークは仕様が挙げるEPLAN「端子台の編集」ダイアログ/ACADE Terminal Strip Editorのままで、**新しい挙動は足していない**。

**新規コンポーネントは作らず**、既存の`DS*`(DSボタン主/副・DS入力欄・DSドロップダウン・DSステッパー・DSラジオ選択/未選択・DSボタン主無効)とトークンだけで組む。DSボードへの追加は2つ(下記)。

## 6. 図面記法(紙面上の描画)

UIトークンとは別系統。紙面は常に白地・黒線で、IEC/ISO/JIS規格を最優先し、規格に無い部分のみ参照図面の産業慣行に従う。正は`.pen`「M2デザイン - 図面記法(規格準拠)」ボードと`docs/internal/specs/m2-drawing-parity.md`:
- 改訂欄=ISO 7200/JIS Z 8311(表題欄直上、下から積む、記号/日付/内容/承認)
- 線番=IEC 62491(ネットごと連番、代表1箇所)
- 配線注記(G2)=配線ごとの「{sq}sq {色} {長さ}m」(例 `0.75sq 白 0.4m`)。代表線分(最長)の中点へ、**線番の反対側**(横線=下・縦線=右)へ2.5mm離す。等幅・文字高2.0mm。画面の表示クラス「配線注記」で消せるが、**SVG/PDFには常に出力**する(参考図面の主情報のため)
- ネットラベルのタグ形状(G3/G19)=`attrs.tag`が`left`/`right`のとき、ネット名を囲む五角形の旗(枠と文字の余白1.0mm・先端の三角2.0mm・線幅0.25mm。文字幅の見積りは等幅前提+1割の余裕)。旗の幅は文字幅に追従する。**基準点は先端の付け根**で、本体は先端と反対側へ伸びる(右向き=本体が左・先端が右、左向きはその鏡像。外形の寸法は左右で同じ)。ネットラベルは必ず配線の頂点に載るので、この向きなら旗が自分の配線・配線注記に乗らない。クロスリファレンスは**本体側**の外(間隔1mm。右向きタグは左へ右揃え、左向きタグは右へ左揃え)。`tag`が無い・知らない値なら従来どおり文字だけ
- 注記文字高(G20)=シートの`annotation_text_mm`(1.0〜3.5mm、未設定=2.0mm)。**配線注記・線番・ネットタグ**の文字と、それぞれの配線からの逃がし量・タグの余白/先端が同じ倍率(設定値÷2.0)で伸縮する。5mmピッチでピンが並ぶ図面は1.4mmにすると注記が隣の行にかからない。表題欄・参照記号・型番・機能ラベルはこの設定では変わらない(図面規格として別)
- 注記テキストの装飾(G4)=基準位置`anchor`(`start`/`middle`/`end` → SVGの`text-anchor`と同じ意味。既定=`start`)・色トークン`color`(上表。未指定=`default`)・`bold`(太字。SVGは`font-weight="bold"`、画面は`600`)。**装飾を付けていない注記の出力は従来と1文字も変わらない**
- シンボルの機能ラベル(G4の第3テキスト欄)=`attrs.function_label`(例「非常停止ボタン」)。参照記号(外形の上4.5mm)・型番(上1.0mm)の**反対側=外形の下3.5mm**へ中央揃え・文字高2.5mm。シンボル定義が`FUNCTION`スロットを持つ場合はその位置(回転・ミラーも追従)。空白だけの値は「無し」と同じ
- バルーン(アイテム番号)=フットプリントの左上角から45°外側へ逃がした白塗りの丸(半径3.5mm・線幅0.3mm)+角と結ぶ引出線(長さ3mm・線幅0.25mm)。番号は等幅・文字高3.0mmで丸の中央。**丸の中は必ず白で塗る**(下の盤面が透けて番号が読めなくならないため)。採番は盤シートの読み順(段=部品の中心の高さ・段の中は左から右)で1..N
- 凡例表=盤シートに置く表(列 No|参照記号|型番、列幅12/22/46mm・行高5mm・文字高2.5mm・外枠0.5mm/罫線0.25mm)。列見出しの下だけ太い罫線。中身は同じシートのフットプリントから導出し、未採番の部品は番号欄を空けて末尾に並ぶ
- 図形(G10)=電気的な意味を持たない作図要素。矩形(対角2点)・線(両端2点)・円(中心+円周上の1点)・折れ線(N点)の4種。線色・塗り色は**注記と同じ色トークン**(既定/強調/注意/良好/補足。生の色コードは不可)、線幅0.1〜2.0mm(既定0.25mm)、破線は3mm/間隔2mm(ハーネス境界と同じ刻み)。塗りは不透明度0.15で、下の配線・記号が透けて読める濃さにする。**配線・シンボルより背面**(ハーネス境界と同じ層)に描く。ネットリスト・ERC・部品表・電線リスト・整頓メトリクスのどれにも出てこない
- **筐体・盤の囲み・強調枠・注記の枠は図形(破線矩形)で描く**(G11)。名前は自由配置のテキスト注記で添える。ハーネス境界を筐体の囲みに流用しない: 囲みに入った配線が全て「そのハーネスに所属」と判定され、電線リスト・端子台チャートのハーネス列が実態と違う名前で埋まるため
- ハーネス境界=**電線をまとめる境界専用**(IEC 61082-1のグループ囲み。まとめて製作・購入する電線束の範囲)。破線囲み(矩形・破線3mm/間隔2mm・線幅0.25mm)、名前は囲みの左上角の外側(右へ1mm・上へ1mm、文字高2.5mm)。クロスリファレンス=「/シート.ゾーン」(例 /2.B3。ネットラベル本文の右脇へ間隔1mm・等幅・文字高2.0mm、相手が複数なら半角空白区切りで列挙、相手がいなければ描かない)
