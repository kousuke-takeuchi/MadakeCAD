# 要件定義書

作成: 2026-08-21 / 対象: MadakeCAD(産業用電気図面CAD)

関連: 設計判断の経緯は[全体設計スペック](../superpowers/specs/2026-08-20-madakecad-design.md)、実装状況は[機能インベントリ](feature-inventory.md)。

## 1. ビジョン(長期目標)

**ロボット・工場設備などの産業設備電気図面を、産業規格に準拠した形で、電気設備設計のベテランでなくても——特にLLM連携によって——簡単に作れ、同時にベテランには産業用CADとして使い勝手の良いツールを、機械CADとの連携や他社最新CADの機能も備えたオープンソースソフトウェアとして提供する。**(2026-08-21明確化)

分解すると5本柱:

| 柱 | 内容 |
|---|---|
| G1 規格準拠 | JIS(将来はIEC 60617/81346等)に準拠した産業設備電気図面。図枠・参照記号・電線管理・帳票 |
| G2 非熟練者+LLM | チャット/エージェントとの対話で、規格や慣習を知らなくても正しい図面が作れる(AI-first) |
| G3 ベテラン品質 | AutoCAD Electrical / EPLAN級の産業CAD機能と操作性。プロの実務に耐える |
| G4 機械CAD連携 | FreeCAD等との部品対応付け・3D配線・電線長還元(SOLIDWORKS Electrical相当) |
| G5 オープンソース | OSSとして公開・配布し、持続的に発展させる(クロスプラットフォーム・多言語・コミュニティ) |

## 2. マイルストーンと成功基準

自社の参考図面の再現やシミュレーションは**最終目標ではなく、途中のマイルストーン**である。

| マイルストーン | 成功基準 | 状態 |
|---|---|---|
| M1 基盤+参考図面クラスの作図 | Commandエンジン/エディタ/JIS図枠/PDF・BOM・電線リスト出力/検証/DCシミュレーション/KiCadインポート/AIチャットが動く | ✅ 概ね達成(フェーズ0〜3) |
| M2 参考図面の完全再現 | 参考図面(社外秘)と同等品質の図面をMadakeCADだけで出図できる(改訂欄・線番・ハーネス境界・クロスリファレンス) | 🔶 残あり |
| M3 AI-first作図 | 非熟練者がチャット指示だけで規格準拠図面を作れる。自動反復(整頓)・マルチプロバイダ・規格知識の内蔵 | ⬜ |
| M4 産業CAD中核機能 | ベテランの実務機能: 端子台チャート・回路マクロ/テンプレート・PLC I/O管理・帳票群・シンボルエディタ | ⬜ |
| M5 機械CAD連携 | FreeCADアドオンで部品対応付け・電線長書き戻し・盤レイアウト | ⬜(Link API土台のみ) |
| M6 OSS公開 | ライセンス選定・公開リポジトリ・Win/Linuxビルド・配布物・i18n・コントリビュートガイド | ⬜ |

## 3. ターゲットユーザー

1. **非熟練の設備設計者**(主・将来): 規格や慣習に詳しくないが、LLMとの対話で正しい図面を作りたい
2. **ベテラン電気設計者**: 産業用CADの慣習的操作(AutoCAD Electrical風)で速く正確に作図したい
3. **AIエージェント**(Claude等): 人間と同じ編集API(MCP/Link API)で図面を読み書きする
4. **OSSコントリビュータ/他社ユーザー**(将来): 自分の環境でビルド・拡張できる
5. 当面の検証ユーザー: 自社のロボット電気設計者(KiCadからの移行。参考図面が品質基準)

## 4. 機能要件

実装状況の詳細は[機能インベントリ](feature-inventory.md)を正とする。要件レベルの一覧:

### 4.1 作図(エディタ)
- JIS C 0617系シンボルの配置(回転・ミラー・参照記号自動採番)、ピン数可変の端子台・コネクタ
- 直交配線(2.5mmグリッドスナップ・ピンスナップ)、ジャンクション、ネットラベル、注記テキスト
- 選択・移動・削除・undo/redo、矩形選択
- 複数シート(シートタブ)、表示クラス(レイヤ)切替
- 部品DBからの部品選択配置(型番・定格の自動設定)

### 4.2 図枠・出力
- JIS図枠(A4〜A0・縦横、ゾーン番号、表題欄、改訂欄)
- SVG / PDF(印刷品質・日本語フォント埋め込み) / 部品表CSV / 電線リストCSV

### 4.3 検証・シミュレーション
- ネットリスト抽出(端子台貫通を含む)
- ERC(未接続ピン・参照記号・宙ぶらりん配線・ラベル競合)
- 電気検証(電源到達性・線径許容電流・電圧降下・ヒューズ定格)— ngspice実解ベース、未導入時は近似
- DC動作点シミュレーション(ネット電圧・部品電流/電力、スイッチ開閉what-if)

### 4.4 部品・電線管理
- グローバル部品DB(型番・メーカ・定格・購入先/データシートURL・価格)
- 電線品番マスタ(線色+sq→品番)、Wireの色・sq・長さ・品番属性

### 4.5 インポート/連携
- KiCad `.kicad_sch` インポート
- 内蔵MCPサーバー(AI用)・Link API(外部ツール用REST+SSE)・`madake` CLI
- アプリ内AIチャット(Claude Code CLI連携、ターン単位undo、編集領域の可視化)

## 5. 非機能要件

| 項目 | 要件 |
|---|---|
| 動作環境 | まずmacOS。コア・連携はOS非依存を維持(Tauriなので移植容易に) |
| データ主権 | ローカルファースト。クラウド同期なし。秘密情報(APIキー等)はOSキーチェーン |
| 保存形式 | 整形JSON(git差分可読)。フォーマット変更は`format_version`+マイグレーション |
| 編集整合性 | 全編集はCommandエンジン経由。UI/AI/CLI/外部APIのどこから編集してもundo/redo・リアルタイム反映が一貫 |
| 印刷品質 | 出力はベクタ(SVG/PDF)。座標はmm 1:1 |
| 応答性 | 参考図面規模(1シート数百要素)でキャンバス操作が滑らかであること |
| テスト | ロジックはRustコアに集中しTDD。UI変更は実機(ブラウザ経由)で検証 |

## 6. 設計原則・制約事項

**設計原則**:

- **産業用CADベンチマーク**: 機能・デザイン・操作性は**AutoCAD Electrical・EPLAN等の高品質産業用電気CADを参考に設計する**。これはベテラン設計者にとって慣習的で使い勝手の良いツールにするため(G3)。リボンUI・部品挿入ダイアログ・検証パネル等の既存デザインもこの方針による
- **AI-firstとプロ向けUIの両立**: 非熟練者向けのLLM対話(G2)と、ベテラン向けの直接操作(G3)は同じCommand API上の2つの入口として共存させる(どちらかの簡略化のために他方を犠牲にしない)
- **UIはPencil(`MadakeCAD.pen`)でデザイン確定後に実装**(design-first)
- 全編集はCommandエンジン経由(architecture.md参照)

**制約事項**:

- 参考図面・実品番などの社外秘情報はリポジトリに含めない(`docs/references/`はgit管理外。OSS公開時の前提)
- PCBレイアウト・ガーバー出力・同時編集は非目標(スペック§8)

## 7. 用語

- **sq**: 電線断面積(mm²)。0.3sq, 0.75sq等
- **参照記号**: R/F/C/D/SW/PB/K(リレー)/J(コネクタ)/TB(端子台)等の部品識別子
- **ネット**: 電気的に接続された配線・ピンの集合
- **ゾーン番号**: 図枠周囲の縦横アドレス(横=数字、縦=英字)
